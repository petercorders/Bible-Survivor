# R12 모세 — 출애굽기 첫 보스 준비

2026-11-18. 전체 R10~R15 승인 범위다. R11 Unity 입력이 고정된 동안에는 이 계획과 외부 아트만 준비하고 Core/DLL/sync 입력은 바꾸지 않는다. R11 소유 반환·리뷰·업로드 후 이 단위의 Core 구현을 시작한다. 새 승인 대기 없음.

## 이야기

초점은 모세 한 번: 귀환과 소명(출2:11~4장) → 바로의 거부·재앙·유월절(출5~12장) → 해방·추격과 홍해(출13~14장). 아론 등은 자기 역할의 조연이다. 3분 안의 세 구간은 사건 압축이며 모든 재앙을 별도 라운드나 적으로 만들지 않는다. 재앙·유월절·구름/불기둥·홍해는 하나님의 행위/배경이며 사탄의 공격으로 바꾸지 않는다. 플레이어가 모세가 되거나 보스 처치 때문에 바다가 갈라졌다고 서술하지 않는다.

보스 `oppression_chariot`/압제의 전차장은 추격의 창작 형상이다. 바로나 이집트 민족을 악마로 그리지 않는다. 일반 전투 뒤 별도 창작 추격 전투를 하고 완료 시 홍해 건넘 배경 전환과 다음 미리암 라운드 안내를 남긴다. 기적은 배경 이야기이며 물벽/익사/호위 HP 등 추가 피해 조건은 없다.

## 보스 초기 계약

HP20000/접촉20/고정400gold, 이동비.30/반경.60/등장offset(0,+3)/안전intro2초는 기존 기준을 재사용한다. 6초 주기로 공격, 첫4.8초에 정지 예고 시작→6초에 고정방향 .6초 실제 돌진. 방향은 예고 시작 때 player 방향으로 고정하고 목표가 겹치면(1,0). 돌진 속도는 기본player속도×1.3(기본값3이면3.9wu/s), 최대 거리2.34wu. 돌진이 끝나면 추적을 재개하고 다음 예고는10.8초/공격12초다. 이는 일반 ex9의 돌진끝 cooldown 시계와 구분한다.

보스 돌진은 실제 몸체 이동과 기존 contact/armor/공통무적 경로로만 피해20을 준다. 예고선 자체·별도 slam·도착점 폭발·추가 피해 패킷은 없다. 빠른 이동에는 player와 boss 양쪽 이동을 포함하는 swept 원 충돌을 써서 통과 누락을 막는다. 동일 tick player 사망 우선/정지·선택 중 시계 정지/치명보스kill 직후 돌진과 경고 제거를 유지한다. 체력60%·30%에서 ex8 각6한번·총12상한, 치명타에 뒤늦은 지원군 없음.

예고는 Core의 현재 원점·저장된 고정 방향·남은 돌진거리·실제 몸체/player 반경에서 투영한다. 기본 body.60+player.25이므로 예고 lane의 center 위험 반폭은.85wu(환경 Tuning이 바뀌면 실제 값을 사용). lowFX에서도 비점멸 이중선과 방향 표식은 배우·무기·선택FX 위/HUD 아래에 유지한다. 원본 PNG에 판정 크기를 새기지 않는다.

## 저장·보상·기존 호환

root schema3은 유지하며 R12 normal/intro/boss/reward/settlement와 완료between13을 지원한다. 보스 방향/돌진 phase·기준시각/만료시각·현재좌표·지원mask·고정후보·선택receipt는 명시적으로 저장/검증한다. 기존 boss2(R03/6)/boss3(R09)·World1~4는 그대로 두고 R12만 최소 named boss4/World5 계약을 도입할 수 있다. 필요한 형식은 Core 담당자가 기존 shape와 대조해 독립 검토하고, 구reader는 새 중첩 버전을 미래형식으로 거절해 원문을 보존한다. 숫자 상한 일괄 치환 금지.

현재 보스는 R12, 이전 R03/R06/R09 세 receipt는 기존 필드로 모두 보존한다. R12 완료between13까지 보스receipt는 현재 Boss로 유지하고 R13 전투용 네 번째 과거receipt 보관은 다음 단위에서 처리한다. R10/R11 fingerprint·root2 창세기·R09→R10 원자적 진입은 바꾸지 않는다.
