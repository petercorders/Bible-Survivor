# Sol–Astra 아이디어 비교 01

2026-11-15 기록. 사용자 승인에 따른 제한된1회 비교이며 제품 코드는 변경하지 않았다.

## 조건

신규 독립 subagent 두 개에 동일한 한국어 입력을 제공했다. 전체 대화 상속 없이 `fork_turns=none`, 지정 모델은 각각 `gpt-6.1-sol`/`gpt-6-astra`, 둘 다 effort `medium`이다. 각1회, 도구/파일/웹/추가agent 금지, 출력1200자 이내를 요청했다. 응답 원문의 전체 usage·resolved model telemetry는 제공되지 않아 요청 지정값과 구분하며 토큰·비용·속도 비교는 하지 않는다.

과제는 R03 노아의 창작 보스 네피림 폭군의 곤봉 예고→타격 표현3안이다. 고정 원형 판정·1.2초 예고/6초 주기·원본 수치/패턴 유지, 저효과·무음·색 외 구분, 좁은 화면/군집/입자, 성경 모티프와 창작 구분, 유료팩/새 렌더 파이프라인 금지를 동일하게 전달했다. 각안의 동작·모티프·대체·구현 위험·검증 및 최종권고를 요청했다.

## 결과 요약

| 관측 | Sol | Astra |
| --- | --- | --- |
| 1안 | 밧줄 원 안의 줄이 당겨져 매듭이 멎는 결속 표현 | 목재 이음매 표식이 순차 연결돼 완성되는 표현 |
| 2안 | 폭군의 목판 낙인·빗금 채움 | 경계에서 중심으로 모이는 균열 |
| 3안 | 곤봉 그림자가 회전·정렬 후 타격 | 곤봉 실루엣이 들린 자세로 변형 후 타격 |
| 최종 권고 | 1안: 줄의 긴장/정지로 시간 전달 | 3안: 공격 도구/타격 시점의 직접 연결 |
| 구체 우려 | 낙인이 지속 장판, 그림자가 좁은 판정으로 오인될 수 있음 | 조립이 안전지대, 균열만 위험 범위로 오인될 수 있음 |

두 응답 모두3안·예고 단계·저효과/무음·창작 구분·구현 위험·검증을 제시했고 고정 판정/주기를 바꾸는 명시적 제안은 없었다. Sol은 공통으로 원 안의 장식·고정 외곽 경계를 강조했다. Astra는 흑백 이중 경계를 적/무기 입자 위에 유지하는 표시 순서를 구체화했다. 이는 부모의 정성 검토이며 실제 게임/사용자 검증이 아니다.

제안 축은 결속/표식/곤봉 그림자로 상당 부분 겹친다. 최종 권고는 다르지만 어느 모델의 권고가 더 읽히는지는 화면 시제품과 사용자 관찰 없이 판정할 수 없다. 이번 표본에서 Astra의 뚜렷한 추가 이득을 관측했다고 주장하지 않는다.

## 운영 결정과 한계

아이디어 생성 기본은 Sol을 유지한다. Astra는 사용자 지정대로 어려운 검증 또는 Sol이 해결하지 못한 문제에만 사용한다. 이번2회는 비교 실험의 예외이며 아이디어마다 중복 호출하는 새 기본값이 아니다. 후보의 참신함·재미·안전 신호 이해도는 실제 시안이 없으므로 미검증이다. 한 과제·각1응답·부모 비블라인드 정성 검토이므로 통계적 모델 우열, 품질 동등성, 토큰/비용 절감을 입증하지 않는다. 노아 전투/아트 구현에 자동 채택하지 않았다.
