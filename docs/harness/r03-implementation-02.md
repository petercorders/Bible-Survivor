## 완료 행동

현재 `boss_reward`의 안정 encounter/receipt와 처치 시 장비·진화 자격을 유지해 정식 최대3개 후보를1회 생성한다. 가능한 진화가 있으면 최소1개를 보장한다. 현재 구현된3무기/보조의 신규1레벨·유효1단계·한 번만 골드100 fallback을 사용하며 슬롯/최대렙/고유 후보를 검사한다. 후보와 선택 ID·정책 version을 저장해 Reload/Retry가 재추첨/중복 지급하지 않게 한다. 기존 pending-v1 보상은 처치 시 저장된 자격/장비와 receipt로 명시1회 승격하며 재추첨 가능한 임시 정책을 정식으로 조용히 바꾸지 않는다.

진화는 무기8·대응 보조1 이상·미진화일 때 같은 슬롯에 적용하고 보조는 유지한다. 첫3종만 공격/후보를 구현한다. 기존 최대 강화 능력을 줄이거나 레벨 보너스를 두 번 더하지 않는다. 미구현7무기를 장착/공격 후보에 넣지 않는다. 진화 후 기본 무기가 다시 새 장비 후보에 나오거나 같은 진화를 반복하지 못하게 한다. 기본 lineage를 유지한 form 기록 등 작은 명시 저장 계약을 사용한다.
