# R14 아론 — 공동체와 우상화의 실패

2026-11-18. 사용자 R10~R15 지속 승인 범위. R12/R13 제품 검증 중에는 계획과 외부 아트만 준비한다. 실제 R14 Core·Unity는 이전 단위 소유 반환·검토·업로드 후 별도 배정한다.

## 이야기

출17~34장의 공동체 여정: 여호수아의 전선과 아론·훌의 손 받침 → 이드로의 분담 조언·시내산 언약·아론의 제사장 부르심 → 금송아지 사건의 실패와 회복을 세 구간에 압축한다. 여호수아·훌·이드로의 자기 행위를 모두 아론에게 귀속하지 않는다. 아론의 라운드가 또 다른 모세 라운드나 같은 아말렉 전투의 반복이 되지 않도록 각 구간 소개문은 짧게 잇는다.

적은 습격·불화·우상화를 형상화한 창작 마물이다. 아론·백성·아말렉 민족 자체를 사탄으로 만들거나 율법·성막·제사장 직분을 저주/적 능력으로 표현하지 않는다. 금가면은 금송아지 우상화의 이미지이며 신성한 성물을 적으로 바꾸지 않는다. 회복을 플레이어 전투 승리로 일어난 성경상 기적이라고 설명하지 않는다.
