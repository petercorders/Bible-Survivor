# 아담 아트03 엔진 연결 단계

승인: 사용자 창세기 개발 지속·디자인 협업 및 2026-11-14 결제 외 재확인 없이 진행 지시. 선행 조건은 아트03 반복02 오프라인 QA PASS와 Unity 아담 UI-02 수정의 독립 재검토 통과다. 그전에는 필요한 폰트·규격 준비만 독립 진행한다.

## 목표와 소유

아트03의 검수된 PNG/manifest/source를 원본으로 두고 아담의 임시 도형을 실제 픽셀 표현으로 교체한다. 코어 전투·수치·R02는 변경하지 않는다. Unity 씬·프리팹·표현·임포터는 단일 Unity 담당이 소유한다. Claude Design 담당은 부족한 디자인/외곽선 폰트 인계 패키지를 별도 폴더로 준비하고 개발 담당과 직접 규격·실화면 피드백을 교환한다. 승인된03 스냅샷을 수정본으로 조용히 덮어쓰지 않는다.

## 작업 단위

1. 픽셀 필터·PPU32·반복02의 구조화 flip·정수 프레임 rect·pivot·레이어 순서·fps/loop·alpha·quality를 읽는 임포터를 만든다. 원본 SHA와 생성 산출물 대응을 확인하고 .meta GUID를 유지한다.
2. 아담 플레이어6레이어의 idle/walk/death, A1/A2/A3, 성경/턱뼈/돌·XP·효과와 풀/생성 상한을 연결한다. 시각 효과를 전투 명중/피해의 원본으로 사용하지 않는다. 저장 복원 후 표현은 기존 world 상태에서 다시 구성한다. 존재하지 않는 공격 프레임을 임의로 늘리지 않는다.
3. 배경/흙길은 지원된16인접 마스크 계약 범위만 사용한다. UI 조각과 한국어 선택 정보·색 외 상태 표식을 연결한다. 기존 작은창 재개·중복선택·정지·저장 회귀를 유지한다. 레벨업/보상/꾸미기 시안이 해당 게임 기능 구현을 뜻하지 않는다.
4. Bitmap TTF의 빈 glyf 문제는 별도 외곽선 폰트 파일·role·원본 버전/해시·라이선스/출처 계약으로 해결하고 실제 Unity 임포트/한국어 렌더를 검증한다. 시스템 fallback으로 아트 글꼴 성공을 대신하지 않는다.

## 검증과 종료

실제 Editor compile/EditMode/PlayMode/macOS 개발 빌드, 표시/애니메이션·방향/정지·저장 재개·작은창/카드/입력 동작을 검증한다. 독립 코드·아트·UI 재검토에서 높은 결함은 수정 후 같은 담당이 재검토한다. 통합 GC 후 커밋·push·해당 SHA CI를 확인한다. 성능 향상을 추정하지 않으며 실측/모바일/기기는 미실행이면 NOT_RUN으로 남긴다. 무료·로컬 범위로 진행하고 결제만 사용자에게 확인한다.
