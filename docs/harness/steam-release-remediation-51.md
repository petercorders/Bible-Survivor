# Steam 출시 후보 검증 #51

#51은 #48의 영구 성장과 #44의 책 완료·모바일 레이아웃을 한 후보로 검증한다. #49와 #46의 증거는 비교 기준과 재실행 입력으로 쓴다. 이번 후보의 실행 결과, 검증 SHA와 남은 출시 조건은 #51의 Draft PR에서 확인한다.

## 진행과 처치 효과

- R09 완료 저장에서는 숫자 1–3, 새 도전 열기, Esc 또는 취소 영역 클릭까지 기존 저장이 그대로 유지된다. 기본 Enter는 이어 가기를 실행한다. 새 도전 확인 영역을 열고 무기를 명시적으로 선택한 경우에만 새 RunId와 R01을 기록한다. 이전 형식과 스키마 4에서 RunId·장비·골드·완주 영수증을 비교한다. 마우스 판정은 새 도전 애니메이션과 같은 위치를 사용한다.
- 적 처치 연출 시험은 실제 월드의 투석 충돌을 사용한다. 밀집 프레임에서는 최대 18칩 예산에 일반 타격보다 처치를 먼저 반영한다. 여러 프레임에 걸쳐 입자 슬롯을 채우는 시험은 프레임 제한과 별도로 풀 드롭 및 일반 타격 슬롯 교체를 검사한다. 저장 재개, 일시정지, 효과 감소, 경고 레이어의 검증 결과는 별도로 기록한다.
- 코어 회귀 검사기는 현재의 `Kill(id, original)` 호출을 대상으로 한다. 격리 소스의 정상 실행, 킬 보상 없는 변이, 복구 실행을 비교하고 #49에서 관측한 실패 이름 열 개와 대조한다.
- 턱뼈의 진화 연쇄 충돌은 현재 도전에서 진화한 무기에만 적용한다. 턱뼈와 광야의 외침이 보스 진입 때 보존한 상태는 정상 웨이브 종료 시각으로 검증한다. 두 저장 회귀 시험은 만료 후 저장·복원, 재생, R04 진입을 확인한다.

## 영구 스킬과 자연 경로

`python3 tools/report_permanent_skill_coverage.py`로 420종·442개 단계 원장을 만든다. 원장에는 구매 연결과 실행 경로, 개별 단계의 발동·경계·저장 재생 근거가 함께 나온다. 발동 근거만 있는 단계와 세 근거가 모두 있는 단계를 별도로 읽는다. 빈 근거는 미확인으로 남긴다. P01, P02, Cross·Staff 조준 및 시작 체력 시험은 `PermanentSkillCombatTests.cs`에서 찾을 수 있다.

거래 시험은 전체 구매 단계와 재로드 및 환불을 검사한다. 442단계가 잠긴 성장 스냅샷의 6무기 기본·진화 재생과 R03 대표 조합 시험은 동시 동작의 근거다. 개별 효과 단정에는 해당 단계의 발동 전후, 경계 바로 양쪽 및 저장을 복원한 다음 동작을 비교한 시험을 기록한다. 전체 조합 재생은 개별 단계의 근거 열을 채우지 않는다.

고정 시드 7·17·29는 #49와 동일한 C7 물맷돌 주무기 우선 정책을 반복한다. 비교 실행에는 실제 정산으로 얻은 프로필을 복사하고, 카탈로그 가용 조건과 현재 잔액을 만족하는 구매를 저장 거래로 적용한 뒤 새 도전을 시작한다. 같은 프로필의 무투자 대조와 무기·성장 선택 정책을 별도로 기록한다. 처치 0은 웨이브에서의 적 수, 발사 및 타격 수, 적과의 거리로 확인한다. 사망한 보스 단계는 피격 종류와 사망 시점, 남은 보스 체력을 비교한다.
