# 주무기별 30노드 스킬트리

주무기 10종마다 6갈래·갈래당 5노드로 30종씩, 총 300종의 노드를 배정한다. 반복 강화 단계는 별도 노드로 세지 않는다. 기초의 숙련·신속·특화는 skill-tree.md에 이미 작성한 노드를 그대로 사용한다. 추가 270종은 아래 효과 개요까지 작성한 상태이며 세부 수치·가격·해금 조건은 후속 밸런스 설계 대상이다.

각 무기의 기초 1번 숙련 뒤 신속과 특화를 선택하는 기존 연결을 유지한다. 다른 갈래는 기초 숙련 뒤 열리고, 갈래 안에서는 번호 순서대로 진행하는 기본안이다. 진화 연계 5노드는 해당 무기를 한 번 진화한 영구 업적이 있어야 구매 가능하고, 구매 후에도 도전에서 실제로 진화해야 효과가 켜진다. 진화 연계 노드를 구매하는 것은 진화의 필수 조건이 아니다.

아래 노드는 자동 공격을 강화한다. 추가 수동 조작을 요구하지 않는다. 조건부 효과는 체력·거리·처치·공격 적중처럼 전투 상황에서 자동 판정한다. 서로 다른 갈래는 함께 투자할 수 있다. 같은 효과가 서로 재발동해 무한 복제되지 않도록 원본 공격·추가 공격·반격을 구분한다. 공격 수량·회복·투사체 제거·방어 효과의 상한과 내부 대기는 수치 설계 시 함께 정한다.

## 회전 성경

책의 개수만 늘리기보다 회전 궤도, 주변 보호, 말씀 파동을 강화한다.

### 기초

1. 성경 숙련: 성경 피해량 +10%p.
2. 성경 신속: 성경 대기시간 -5%p.
3. 한 권 더: 회전하는 책 +1권.
4. 빠른 첫 장: 라운드 진입 후 첫 성경 생성의 대기시간 감소.
5. 큰 책장: 책 자체의 충돌 크기 증가, 회전 반경은 유지.

### 회전 궤도

1. 속독: 책의 회전속도 증가.
2. 바깥 궤도: 적이 많은 방향에서 궤도가 잠깐 넓어짐.
3. 안쪽 궤도: 추가된 책 한 권을 가까운 반경에 배치.
4. 교차 회전: 안쪽 책은 바깥 책과 반대로 회전.
5. 왕복 궤도: 성경 생성 주기마다 궤도가 부드럽게 넓어졌다 좁아짐.

### 수호

1. 단단한 표지: 성경의 밀쳐내기 증가.
2. 접근 차단: 아주 가까운 적에게 성경의 밀쳐내기 추가 증가.
3. 펼친 방패: 책에 닿은 적 투사체를 일정 확률로 제거.
4. 위기의 표지: 낮은 체력에서 성경의 충돌 크기 일시 증가.
5. 마지막 장벽: 피해를 받으면 한 번의 짧은 성경 충격파 발생.

### 페이지

1. 낱장: 책 적중 시 일정 확률로 작은 페이지 투사체 생성.
2. 잉크 자국: 페이지가 지나간 짧은 경로에 약한 잔류 피해.
3. 다음 구절: 페이지가 처음 적중한 적 뒤로 한 번 더 날아감.
4. 책갈피: 성경에 맞은 적을 잠깐 표시해 다음 페이지 피해 증가.
5. 흩날리는 장: 성경이 사라질 때 남은 책마다 페이지 방출.

### 순환

1. 긴 독서: 성경 지속시간 증가.
2. 이어 읽기: 성경으로 일정 수 처치하면 현재 지속시간 소폭 연장.
3. 돌아오는 책: 사라지는 책이 플레이어 쪽으로 돌아오며 한 번 타격.
4. 여백의 빛: 성경이 꺼진 동안 가까운 범위에 약한 빛의 피해.
5. 다시 펼치기: 지속 중 정예를 처치하면 다음 대기시간 일부 감소.

### 진화 연계

1. 넓은 성역: 말씀 파동 반경 증가.
2. 두 번째 울림: 일정 횟수마다 약한 추가 파동 발생.
3. 성역의 경계: 파동 외곽에 맞은 적을 추가로 밀침.
4. 중심의 말씀: 파동이 놓친 가까운 적을 안쪽 책이 우선 타격.
5. 겹친 성역: 정예 처치 시 잠깐 작은 성역을 그 자리에 남김.

## 삼손의 턱뼈

근접 휘두르기, 강한 밀쳐내기, 적 무리 돌파에 집중한다.

### 기초

1. 턱뼈 숙련: 턱뼈 피해량 +10%p.
2. 턱뼈 신속: 공격 주기 -5%p.
3. 연속 휘두르기: 한 주기의 타격 +1회.
4. 긴 팔: 휘두르기의 도달 거리 증가.
5. 묵직한 끝: 휘두르기 끝부분에 맞은 적의 피해 증가.

### 휘두르기

1. 넓은 호: 휘두르기 각도 증가.
2. 되치기: 다음 추가 타격이 반대 방향에서 이어짐.
3. 등 뒤의 일격: 일정 주기마다 뒤쪽에 약한 타격 추가.
4. 내려찍기: 연속 타격의 마지막 공격을 좁고 강한 내려찍기로 변경.
5. 사방의 턱뼈: 일정 횟수마다 네 방향에 짧은 타격.

### 괴력

1. 강한 손목: 기본 밀쳐내기 증가.
2. 무거운 상대: 높은 체력의 적에게 추가 피해.
3. 갑주 깨기: 반복 적중한 정예가 턱뼈에 받는 피해 증가.
4. 땅 울리기: 내려찍기가 짧은 전방 충격파 생성.
5. 벽 없는 돌파: 한 타격에 여러 적을 맞히면 밀쳐내기 추가 증가.

### 연전

1. 첫 쓰러짐: 한 주기에서 첫 처치 시 다음 타격 피해 증가.
2. 이어지는 힘: 연속 처치 중 짧게 공격속도 증가.
3. 끊기지 않는 팔: 정예 처치 시 다음 타격을 빠르게 시작.
4. 군세 상대: 한 타격에 맞은 적 수에 따라 다음 공격 범위 소폭 증가.
5. 천인 돌파: 일정 누적 처치마다 강한 광역 휘두르기 발동.

### 근접 생존

1. 거리 확보: 매우 가까운 적에 대한 밀쳐내기 증가.
2. 상처의 반격: 실제 피격 후 다음 턱뼈 타격 강화.
3. 숨 고르기: 정예를 턱뼈로 처치하면 소량 회복.
4. 흔들리지 않음: 휘두르는 동안 접촉 피해를 소폭 경감.
5. 포위 돌파: 주변 적 수가 많으면 다음 타격을 원형으로 확장.

### 진화 연계

1. 깊은 충격: 천인의 힘의 충격파가 더 멀리 진행.
2. 연쇄 붕괴: 강하게 밀린 적이 다른 적에 닿으면 약한 충돌 피해.
3. 굳센 연격: 연속 타격의 마지막 공격에 정예 추가 피해.
4. 넓은 돌파로: 진화 내려찍기 뒤에 한 번의 부채꼴 파동.
5. 끝나지 않는 괴력: 정예 처치 후 잠깐 연속 타격 횟수 증가.

## 다윗의 물맷돌

정밀 사격, 빠른 연사, 도탄 중 어떤 방향을 먼저 키울지 선택한다.

### 기초

1. 물맷돌 숙련: 물맷돌 피해량 +10%p.
2. 물맷돌 신속: 발사 주기 -5%p.
3. 추가 투석: 한 주기의 발사 수 +1.
4. 단단한 돌: 돌의 충돌 크기 증가.
5. 빠른 돌팔매: 돌의 비행속도 증가.

### 정밀

1. 거인 조준: 사거리 안 정예·보스를 우선 표적으로 선택.
2. 약점 노리기: 물맷돌의 치명타 확률 증가.
3. 깊은 상처: 물맷돌 치명타 피해 증가.
4. 같은 표적: 같은 적에게 연속 적중하면 해당 연사의 후속 피해 증가.
5. 결전의 한 발: 일정 주기마다 큰 적에게 강화된 첫 돌 발사.

### 연사

1. 빠른 손: 한 연사 안의 돌 사이 간격 감소.
2. 나눠 쏘기: 정예가 없으면 연사의 표적을 가까운 적들에게 분산.
3. 빈틈 사격: 처치로 표적이 사라지면 다음 돌을 즉시 새 적에게 조준.
4. 추가 장전: 일정 주기마다 마지막 돌을 한 발 더 발사.
5. 돌비: 일정 누적 적중마다 짧은 추가 연사.

### 도탄

1. 튀는 돌: 첫 적중 뒤 한 번 도탄.
2. 넓은 도약: 도탄이 찾는 다음 표적의 거리 증가.
3. 남는 힘: 도탄 후 피해 감소를 완화.
4. 갈라진 파편: 마지막 도탄에서 약한 돌 파편 방출.
5. 돌아오는 돌: 도탄 표적이 없으면 되돌아오며 한 번 타격.

### 관통

1. 꿰뚫기: 돌의 관통 수 +1.
2. 일렬 조준: 주변에 일렬로 선 적이 있으면 그 방향 우선 발사.
3. 깊이 파고들기: 관통 후 피해 감소 완화.
4. 끝의 파열: 관통을 모두 소모한 돌이 작은 범위 타격.
5. 길 뚫는 돌: 일정 주기마다 관통 제한이 없는 한 발 발사.

### 진화 연계

1. 다섯 돌의 집중: 진화 연사의 첫 표적에 후속 돌을 더 정확히 집중.
2. 다섯째의 무게: 기본 다섯 돌 연사의 다섯째 돌 강화.
3. 거인의 흔들림: 보스에 일정 횟수 적중하면 다음 연사에 추가 피해.
4. 흩어지는 승리: 정예를 처치한 돌에서 일반 적을 향한 파편 방출.
5. 한 발의 결단: 일정 주기마다 첫 돌이 치명타로 적중.

## 모세의 지팡이

물길을 넓히고, 적을 밀어내고, 물길을 따라 지속 피해를 만든다.

### 기초

1. 지팡이 숙련: 물결 피해량 +10%p.
2. 지팡이 신속: 물결 주기 -5%p.
3. 갈라지는 물결: 한 주기의 물결 수 +1.
4. 먼 물길: 물결의 이동 거리 증가.
5. 거센 흐름: 물결의 이동속도 증가.

### 물길

1. 넓은 수로: 물결 폭 증가.
2. 물결 사이: 여러 물결 사이 간격을 넓혀 전방을 고르게 타격.
3. 모이는 흐름: 정예가 가까우면 여러 물결이 그 방향으로 수렴.
4. 돌아오는 파도: 물결 끝에서 약한 역방향 파도 생성.
5. 굽은 수로: 물결이 가까운 적 쪽으로 완만하게 휘어짐.

### 파도

1. 밀어내는 물: 물결의 밀쳐내기 증가.
2. 솟는 물기둥: 끝 지점에서 짧은 원형 타격.
3. 무거운 파도: 가까운 적에게 물결 피해 증가.
4. 부서지는 물보라: 정예 적중 시 주변으로 약한 물보라.
5. 넘실대는 힘: 일정 주기마다 폭이 큰 강화 파도 발사.

### 잔류 수로

1. 젖은 길: 물결이 지나간 자리에 잠깐 약한 피해 구역.
2. 긴 물길: 잔류 구역 지속시간 증가.
3. 갈라진 지면: 잔류 구역 가장자리에 닿은 적 추가 타격.
4. 흐름의 교차: 수로가 겹친 지점에 한 번의 물기둥.
5. 밀려오는 끝물: 수로가 사라질 때 약한 마지막 파동.

### 보호

1. 가까운 물막이: 발사 직전 플레이어 앞에 짧은 물막 타격.
2. 막아선 파도: 물결에 맞은 적 투사체를 일정 확률로 제거.
3. 빈틈의 수로: 피격 후 다음 물결을 빠르게 생성.
4. 길 위의 발걸음: 자신의 잔류 수로 위에서 이동속도 소폭 증가.
5. 둘러싼 물벽: 주변 적이 많으면 일정 간격으로 약한 원형 물결.

### 진화 연계

1. 넓은 홍해의 길: 진화 수로 폭 증가.
2. 양옆의 물벽: 수로 양쪽 가장자리의 피해 강화.
3. 긴 통로: 진화 수로 지속시간 증가.
4. 밀려드는 귀환: 진화 수로 종료 때 되돌아오는 큰 파도.
5. 열린 길: 정예 처치 지점에 짧은 추가 수로 생성.

## 다니엘의 사자

추적·협공·포효·귀환 동작으로 소환수의 특색을 살린다. 사자에게 별도 체력이나 장비 슬롯은 만들지 않는다.

### 기초

1. 사자 숙련: 사자 피해량 +10%p.
2. 사자 신속: 타격 주기 -5%p.
3. 사자의 동행: 소환 사자 수 +1.
4. 빠른 추격: 사자의 이동속도 증가.
5. 긴 발톱: 근접 타격 거리 증가.

### 추적

1. 큰 먹잇감: 가까운 정예를 우선 추적.
2. 먼 사냥: 플레이어에게 돌아오기 전 활동 반경 증가.
3. 뛰어들기: 멀리 있는 표적에게 짧게 도약.
4. 빈틈 없는 추격: 표적 처치 후 다음 적을 빠르게 선택.
5. 사냥의 마침표: 낮은 체력의 일반 적에게 추가 피해.

### 협공

1. 표적 분담: 일반 적이 많으면 사자별 표적 중복 최소화.
2. 집중 포위: 보스 하나만 남으면 사자들의 공격 간격을 엇갈리게 배치.
3. 맞물린 발톱: 다른 사자가 친 적에게 후속 타격 피해 증가.
4. 사냥 표식: 정예에게 사자의 표식을 남겨 사자 피해 강화.
5. 동시 도약: 일정 주기마다 사자들이 각 표적에 도약 공격.

### 포효

1. 짧은 포효: 일정 간격으로 가까운 적에게 약한 원형 타격.
2. 큰 울림: 포효 반경 증가.
3. 위협의 소리: 포효의 밀쳐내기 증가.
4. 사냥의 신호: 포효 후 잠깐 사자 타격속도 증가.
5. 겹치지 않는 울림: 여러 사자의 포효가 차례대로 발생.

### 호위

1. 가까운 순찰: 한 사자가 주기적으로 플레이어 근처를 순찰.
2. 위험 감지: 가까운 적이 많으면 순찰 사자가 그쪽으로 도약.
3. 귀환의 발톱: 복귀 경로의 적을 한 번씩 타격.
4. 보호의 포효: 피격 후 순찰 사자가 주변 적을 밀침.
5. 안전한 거리: 사자가 가까운 정예를 처치하면 짧은 피해 경감.

### 진화 연계

1. 수호자의 도약: 진화 사자의 도약 피해 강화.
2. 연속 덮치기: 도약 처치 후 추가 도약 한 번.
3. 큰 사냥터: 진화 사자의 타격 반경 증가.
4. 수호의 울림: 진화 포효가 적 투사체를 일정 확률로 제거.
5. 무리의 수호자: 진화 후 일반 사자들도 강화된 협공 표식 공유.

## 불기둥

점화 위치·불길 확산·불씨·지역 유지로 지속 피해 무기를 만든다.

### 기초

1. 불기둥 숙련: 불기둥 피해량 +10%p.
2. 불기둥 신속: 생성 주기 -5%p.
3. 쌍불기둥: 한 주기의 생성 수 +1.
4. 넓은 불자리: 기본 불기둥 반경 증가.
5. 빠른 첫 불꽃: 생성 후 첫 피해까지의 지연 감소.

### 점화 위치

1. 군집 점화: 적이 밀집한 위치를 우선 선택.
2. 정예 점화: 가까운 정예의 위치를 우선 선택.
3. 진로 점화: 적의 이동 방향 앞쪽에 불기둥 생성.
4. 겹침 줄이기: 여러 불기둥을 인접한 서로 다른 위치에 배치.
5. 둘러싼 불: 일정 주기마다 플레이어 주변에 작고 짧은 불기둥 생성.

### 지속

1. 오래 타기: 불기둥 지속시간 증가.
2. 중심의 열: 중심에 있는 적에게 추가 피해.
3. 남은 불자리: 종료 지점에 약한 잔류 불길.
4. 끈질긴 열기: 불기둥에 반복 적중한 적의 후속 불 피해 증가.
5. 이어지는 불꽃: 정예 처치 시 해당 불기둥 지속시간 소폭 연장.

### 확산

1. 날리는 불씨: 일정 타격마다 가까운 적에게 작은 불씨 발사.
2. 번지는 열: 불씨 적중 지점에 작은 불자리 생성.
3. 뜨거운 전이: 처치된 적 주변에 한 번의 약한 화염 타격.
4. 이어 붙은 불길: 인접 불기둥 사이에 짧은 불길 연결.
5. 큰 점화: 일정 누적 처치마다 다음 불기둥의 범위 증가.

### 화염 주기

1. 상승하는 불: 생성 직후 첫 타격 강화.
2. 내려앉는 재: 종료 시 작은 범위 타격.
3. 열의 축적: 같은 적이 계속 머무르면 타격 간격 소폭 감소.
4. 재점화: 불기둥이 정예를 처치하면 짧은 추가 불기둥 생성.
5. 불의 맥박: 일정 주기마다 유지 중인 불기둥이 동시에 한 번 타격.

### 진화 연계

1. 구름의 길: 이동 불기둥이 남기는 불길 지속 증가.
2. 느린 순찰: 적 군집에서 진화 불기둥이 천천히 움직여 집중 피해.
3. 옮겨 붙는 인도: 군집 처치 후 다음 군집으로 빠르게 이동.
4. 두른 열기: 구름 가장자리에 약한 추가 피해 구역.
5. 광야의 화염길: 일정 이동 거리마다 작은 불자리를 남김.

## 하늘의 번개

표적 선정, 단일 낙뢰, 연쇄, 지면 전류를 구분한다.

### 기초

1. 번개 숙련: 번개 피해량 +10%p.
2. 번개 신속: 낙뢰 주기 -5%p.
3. 추가 낙뢰: 한 주기의 낙뢰 수 +1.
4. 넓은 낙점: 낙뢰 반경 증가.
5. 빠른 벼락: 낙뢰 표적 결정 후 타격 지연 감소.

### 표적

1. 군집 탐지: 밀집한 적을 우선 타격.
2. 높은 위협: 정예와 보스에 낙뢰 우선 배정.
3. 고른 낙뢰: 한 주기의 낙뢰를 가능한 서로 다른 적에게 배정.
4. 끝까지 추적: 타격 전 표적이 죽으면 낙뢰를 다른 적으로 전환.
5. 고독한 적: 주변 적이 적을 때 단일 표적 피해 증가.

### 강타

1. 깊은 벼락: 높은 체력의 적에 대한 피해 증가.
2. 순간 치명: 번개의 치명타 확률 증가.
3. 잔류 전하: 같은 적에 짧은 시간 내 재적중하면 추가 피해.
4. 벼락의 끝: 마지막 낙뢰의 범위 증가.
5. 겹친 천둥: 일정 주기마다 정예 표적에 약한 후속 낙뢰 한 번.

### 전도

1. 작은 불꽃: 기본 번개가 가까운 적에게 약한 전류 한 번 전달.
2. 먼 전도: 추가 전류의 표적 탐색 거리 증가.
3. 남은 전압: 전달 과정의 피해 감소 완화.
4. 전하 표식: 전류에 맞은 적이 다음 원본 낙뢰에 받는 피해 증가.
5. 끊긴 전류: 다음 표적이 없으면 마지막 적에 작은 추가 충격.

### 지면 전류

1. 낙뢰 자국: 타격 지점에 짧은 전류 구역.
2. 넓은 균열: 전류 구역 반경 증가.
3. 남는 전기: 전류 구역 지속시간 증가.
4. 이어진 지면: 가까운 낙뢰 자국 사이에 한 번의 직선 전류.
5. 땅의 울림: 일정 낙뢰 횟수마다 큰 원형 전류 타격.

### 진화 연계

1. 깊은 연쇄: 진화 연쇄의 최대 전달 횟수 증가.
2. 갈라진 낙뢰: 진화 연쇄의 첫 갈림에서 약한 추가 전류 생성.
3. 우레의 폭: 천둥 충격파 반경 증가.
4. 폭풍 표식: 정예에 연쇄가 도달하면 다음 원본 낙뢰 강화.
5. 폭풍의 중심: 일정 주기마다 가장 큰 군집에 강화된 낙뢰.

## 십자가

왕복 궤적, 되돌아오는 타격, 잔광과 가시를 강화한다.

### 기초

1. 십자가 숙련: 십자가 피해량 +10%p.
2. 십자가 신속: 발사 주기 -5%p.
3. 쌍십자가: 한 주기의 십자가 수 +1.
4. 긴 비행: 돌아서기 전 이동 거리 증가.
5. 큰 날개: 십자가 충돌 크기 증가.

### 나아가는 길

1. 빠른 전진: 전진 비행속도 증가.
2. 정예 조준: 가까운 정예를 향해 발사.
3. 넓은 펼침: 다중 십자가 발사 각도를 넓힘.
4. 첫 타격: 전진 첫 적중 피해 증가.
5. 끝의 회전: 돌아서는 지점에서 짧게 회전하며 추가 타격.

### 돌아오는 길

1. 빠른 귀환: 귀환 비행속도 증가.
2. 귀환의 무게: 돌아오는 십자가 피해 증가.
3. 다른 귀로: 귀환 경로를 조금 휘게 해 새로운 적 타격.
4. 지나온 표적: 전진에 맞은 적을 귀환에 맞히면 추가 피해.
5. 두 번째 순회: 일정 주기마다 약한 십자가가 한 번 더 왕복.

### 관통과 회전

1. 긴 관통: 발사체가 통과 가능한 적 수 증가.
2. 회전의 테두리: 십자가 외곽 타격 범위 증가.
3. 다중 적중: 한 왕복에 여러 적을 맞히면 후반 경로 피해 증가.
4. 꿰뚫는 귀환: 일정 주기마다 귀환 십자가의 관통 제한 제거.
5. 교차점: 서로 다른 십자가 경로가 교차하면 작은 빛 타격.

### 잔광

1. 빛의 흔적: 지나간 경로에 짧은 약한 잔광.
2. 오래 남는 빛: 잔광 지속시간 증가.
3. 돌아온 빛: 귀환 경로의 잔광 피해 증가.
4. 가시의 예고: 정예 적중 지점에 한 번의 작은 빛 가시.
5. 흩어진 광휘: 정예 처치 시 짧은 빛 조각 방출.

### 진화 연계

1. 긴 수난의 길: 진화형의 가시 흔적 지속 증가.
2. 겹친 가시: 왕복 경로가 겹친 곳의 가시 피해 증가.
3. 넓은 광휘: 진화 가시의 타격 반경 증가.
4. 부서지는 속박: 귀환 종료 지점에 한 번의 원형 빛 파동.
5. 수난의 순회: 일정 주기마다 진화 십자가가 추가 회전 후 귀환.

## 광야의 외침

전방 음파의 각도·압력·발성 리듬을 키우고 사방 메아리는 진화 후에 연다.

### 기초

1. 외침 숙련: 음파 피해량 +10%p.
2. 외침 신속: 발성 주기 -5%p.
3. 넓은 외침: 외침 범위 +20%p.
4. 먼 목소리: 음파 도달 거리 증가.
5. 빠른 첫 음절: 발성 시작 후 첫 타격 지연 감소.

### 발성

1. 긴 호흡: 외침 지속시간 증가.
2. 강한 첫말: 첫 타격 피해 증가.
3. 끝의 외침: 마지막 타격의 밀쳐내기 증가.
4. 흔들리지 않는 발성: 이동 중에도 마지막 조준 방향을 안정적으로 유지.
5. 마무리 음절: 일정 주기마다 마지막 음파 타격 강화.

### 방향

1. 넓은 입구: 전방 부채꼴 각도 증가.
2. 중심의 울림: 부채꼴 중심에 있는 적에게 추가 피해.
3. 가장자리 울림: 부채꼴 양끝의 밀쳐내기 증가.
4. 군세를 향해: 발성 시작 시 가까운 최대 군집을 자동 조준.
5. 방향 전환: 발성 사이에 뒤쪽 적이 많으면 다음 외침을 그쪽으로 조준.

### 압력

1. 밀어내는 소리: 음파의 기본 밀쳐내기 증가.
2. 가까운 압력: 아주 가까운 적에 추가 밀쳐내기.
3. 굳센 표적: 같은 정예가 반복 적중하면 음파 피해 증가.
4. 날아오는 위협: 음파가 닿은 적 투사체를 일정 확률로 제거.
5. 몰아치는 끝말: 일정 누적 적중마다 강한 마지막 음파.

### 리듬

1. 호흡 정리: 한 번의 외침에서 일정 수 처치하면 다음 대기 소폭 감소.
2. 쉬지 않는 선포: 정예 처치 후 짧게 발성 주기 감소.
3. 깊은 울림: 연속 적중한 적에 후반 타격 피해 증가.
4. 위기의 외침: 실제 피격 후 다음 발성 범위 증가.
5. 길어진 선포: 일정 누적 처치마다 다음 발성 지속시간 증가.

### 진화 연계

1. 사방의 선포: 진화 사방 음파의 반경 증가.
2. 먼 메아리: 메아리가 퍼지는 거리 증가.
3. 연속 메아리: 일정 주기마다 약한 메아리 한 번 추가.
4. 중심의 고요: 진화 음파가 가까운 적을 더 강하게 밀침.
5. 광야의 대합창: 정예 처치 후 잠깐 사방 메아리 주기 감소.

## 엘리야의 불수레

돌진 경로, 전차 행렬, 회오리, 남는 불길을 강화한다.

### 기초

1. 불수레 숙련: 불수레 피해량 +10%p.
2. 불수레 신속: 등장 주기 -5%p.
3. 불수레 행렬: 한 주기의 불수레 수 +1.
4. 넓은 차체: 불수레의 충돌 폭 증가.
5. 빠른 출발: 생성 후 돌진 시작 지연 감소.

### 돌진 경로

1. 긴 돌파: 수레의 이동 거리 증가.
2. 큰 군세 조준: 발사 시 적이 밀집한 방향을 선택.
3. 정예 관통: 정예를 향해 경로를 우선 배정.
4. 완만한 선회: 돌진 중 한 번 가까운 군집 쪽으로 약하게 선회.
5. 돌아온 불말: 일정 주기마다 약한 수레가 반대 방향으로 추가 통과.

### 행렬

1. 넓은 대열: 다중 수레의 평행 간격 증가.
2. 모이는 대열: 보스만 남으면 수레 경로를 보스 쪽으로 수렴.
3. 시간차 돌진: 다중 수레가 짧은 간격을 두고 출발.
4. 마지막 수레: 행렬 마지막 수레의 피해 증가.
5. 교차 행렬: 일정 주기마다 두 방향에서 수레가 교차.

### 화염 바퀴

1. 바퀴의 불씨: 적중 시 작은 불씨가 옆으로 튐.
2. 시작의 불꽃: 수레 출발 지점에 짧은 불자리.
3. 끝의 화염: 수레가 사라지는 위치에 작은 폭발.
4. 불길의 폭: 바퀴가 남기는 약한 흔적의 폭 증가.
5. 태우는 행렬: 일정 수의 적을 통과한 수레의 마지막 폭발 강화.

### 바람

1. 돌파의 바람: 수레 앞쪽 적에 밀쳐내기 추가.
2. 뒤따르는 바람: 수레 뒤에 약한 바람 타격이 한 번 따라감.
3. 넓은 여파: 바람 타격 폭 증가.
4. 흩어지는 화살: 수레에 닿은 적 투사체를 일정 확률로 제거.
5. 폭풍의 진입: 일정 주기마다 강화된 바람을 두른 수레 생성.

### 진화 연계

1. 큰 회오리: 진화 수레의 회오리 반경 증가.
2. 긴 불길: 진화 수레의 잔류 불길 지속 증가.
3. 불과 바람의 교차: 서로 다른 진화 수레 경로가 교차하면 작은 화염 회오리.
4. 거센 승천: 수레가 사라질 때 위로 솟는 불꽃 타격.
5. 승천의 행렬: 정예 처치 후 다음 진화 행렬의 수레 한 대를 추가.

## 수치화할 때 지킬 범위

- 현재 확정된 기초 3노드의 가격은 유지한다. 추가 노드의 가격·수치·업적 조건은 별도 표로 작성한다.
- 일정 주기·일정 확률·정예 처치 발동에는 반드시 내부 대기와 효과 상한을 지정한다.
- 치명타·도탄·관통·투사체 제거 같은 새 동작은 공통 무기 계산 규칙을 먼저 정하고 연결한다.
- 도탄·파편·잔류 피해·반격에서 다시 같은 생성 효과를 발동시키지 않는다.
- 분산·수렴·우선 표적 규칙이 충돌하면 보스 단일 표적 → 정예 → 군집 → 가까운 적 순서로 정리한다. 여러 조건이 동시에 켜진 경우의 세부 우선순위는 해당 무기 수치표에 명시한다.
- 모든 고유 노드가 첫 창세기 도전부터 열리는 것은 아니다. 진행 업적과 선행 조건을 통해 구약의 긴 여정에서 확장한다.
- 효과 개요 300종은 작성되었지만 300종의 구현·밸런스·가격 검증이 완료된 것은 아니다.
