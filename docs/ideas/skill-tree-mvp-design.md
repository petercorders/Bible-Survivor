## 진입과 진행

- 최초 시작, 사망 뒤, 책 완료, 일시정지에서 트리를 연다. 활성 도전에서는 먼저 성공적으로 체크포인트를 저장한다. 닫으면 원래 화면으로 돌아간다. 재개는 도전의 기존 스냅샷을 사용한다. 신규 시작의 허용 조건은 Host의 기존 전환을 따른다.
- 공통 세부 트리 12개와 무기별 트리 10개를 모두 탐색할 수 있다. 무기·진화·정산 잠금의 이유, 잔액, 랭크, 다음 효과·가격, 적용 형태를 표시한다. 다른 트리 선행 노드에 바로 이동할 수 있다. 구매 또는 환불을 성공한 뒤 새 도전에 반영된다고 표시한다.
- Rnn은 계정의 최고 **정산 완료** Rnn 이상을 의미한다. 일반 라운드 완료 또는 보스 보상·대기 성장 해결 후 정산 커밋 때 올린다. 전투 중 달성이나 취소한 선택은 세지 않는다. 죽거나 새 도전을 시작해도 내려가지 않는다. 무기 및 진화 업적과 별개다.
- 최초 R01에서는 획득 범위 60골드, 체력 80골드, 공격력 100골드를 구매할 수 있다. 물맷돌의 최소 600골드 경로는 공격력 → 숙련 → 추가 투석이다. 무기별 일반 갈래는 R03부터, 최종 공통·진화 갈래는 R150에 열린다. 비용과 시점은 초기 경제안이다. 진행 잠금이 열려도 결제액이 충분해야 한다.
- 전체 비용은 공통 108,050골드, 무기별 각 27,000골드(10종 270,000골드), 총 378,050골드다. 기초 38종의 21,950골드를 포함한다. 최대 랭크까지 442회 결제한다. R60 저장(65,115골드)의 최저가 순 구매는 153종·169랭크에 64,980골드를 써 135골드가 남는다. R180 저장(429,115골드)은 375종·397랭크에 320,000골드를 써 109,115골드가 남는다. 두 표본 모두 전 무기 해금과 물맷돌 진화의 증거가 있으며, R180의 남은 45종은 나머지 9개 진화 업적을 요구한다. 이 값은 문서 가격표 계산이다.
- 모든 신규 노드는 1랭크다. 랭크가 높은 단계에서 새로운 선행 조건이 추가되는 노드는 없다. 최고 조건(R150 정산과 파생 무기별 진화 업적)은 한 도전에 동시에 채울 필요가 없다. 다음 도전에서도 영구 기록과 골드가 이어진다.

## 합산과 발동

### 계산 순서와 상한

기본 무기 레벨 또는 진화형을 먼저 선택한다. 기본 스탯과 도전 시작 시 저장한 공통·전용 랭크, 현재 전투 보조 및 해당 이벤트의 조건을 합성한다. 아래 상한은 새 전투 규칙에 적용한다. `+N%p`는 선형 가산이고 `×`와 절대값 교체는 가산 뒤 해당 값에 적용한다. 공격력 및 범위 효과를 각 계층에서 다시 곱하지 않는다. 길이와 폭은 월드 단위, 각도는 도, 시간은 전투 초다. 폭은 전체 폭, 명시된 반경·반각은 절반 치수다.

| 항목 | 가산 및 최종 상한 |
|---|---|
| 피해 | 기본 피해 × `min(2.25, 1 + 공통 + 전용 + 머리카락(단계당 10%p) + 조건 + 대상 표식)`. 명시된 관통 감쇠·보조 타격 계수를 이후 적용하고 원본만 치명 판정을 한다. 치명 전 원본 피해가 1 미만이면 1, 배정 피해는 부동소수 값으로 유지한다. |
| 치명 | 기본 확률 0%, 합산 35% 상한. 치명 배율 기본 1.5, 합산 2.0 상한. 확정 치명은 확률 상한의 예외이며 치명 배율 상한을 그대로 적용한다. 같은 대상에 같은 타격 이벤트마다 최대 한 번 판정한다. |
| 주기 | 대기부 × `max(0.20, 1 - 합산 감소)`. 우레 단계당 8%p를 포함한다. 성경은 활성부 + 대기부, 진화 성경의 대기부 0은 그대로다. 나머지 7종과 턱뼈·물맷돌은 시작→시작 주기다. 주기 단축·초 단위 선행 모두 적용 뒤 직전 개시와 다음 개시 간 최소 0.15초이며 연사명세의 배치가 먼저 끝나야 한다. |
| 내부 간격 | 연사 간격은 공통·전용 합산 최대 25%p 감소, 하한 0.05초. 고정 원본 타격 간격은 최대 20%p 감소, 하한 0.40초(기본 설정이 이보다 짧은 독립 연사에는 연사 하한 적용). 자동 반복 보조 타격 하한 0.50초. 첫 발생 지연이 지정된 신규 무기의 지연 하한은 0.05초다. |
| 치수 | 레벨별 기본 배율에 공통·전용·회오리바람(단계당 +10%p)을 합산하고 2.50배(동일 치수의 Lv.1 시작점 대비)로 제한한다. 회오리바람은 타격 폭·반경·근접 도달에 적용한다. 순수 비행 거리·추적거리·궤도 반경·발사체 충돌 크기는 해당 항목 효과만 합산한다. 호 반각은 기본형 최대 90°, 명시된 360° 및 진화 원형은 예외다. |
| 지속·속력 | 기본 × `min(1.75,1+보너스)`. 구름기둥 +10%p/단계는 지속 공격의 활성부·주 구역에만, 동풍 +10%p/단계는 이동 투사체·수레·물결 속력에 적용한다. 보조 타격 수명은 행의 기본값에 대상이 되는 공통·전용만 붙인다. 연장과 지연 변경도 적용한 최종 수명의 상한은 생성 시 기본값 ×1.75다. 정해진 거리 또는 귀환 완료로 먼저 끝날 수 있다. 기본 사자의 소환 시간은 무한이며 구름기둥은 할퀴기·소환에 적용하지 않는다. |
| 기본 수량 | 진화형 기본 수량을 고른 뒤 특화와 보조를 한 번씩 더한다. 다섯 돌은 기존 3종의 주기 수량에 최대 +2를 유지하며 신규 7종의 주기 수량에는 적용하지 않는다. 원본 수량 상한 `bible=7, jawbone=6, sling=8, moses_staff=4, daniel_lion=3, fire_pillar=3, lightning=4, cross=3, wilderness_voice=1, elijah_chariot=4`. 추가 타격의 별도 예산은 아래 적용. |
| 관통·밀침 | 유한 발사체는 접촉 적중 예산 최대 8(십자가는 편도마다 새 예산). 무한 관통 기본형은 투사체 생존·대상당 타격 제한을 유지한다. 밀침은 원본 타격당 최대 1.0단위, 보스 본체의 위치와 예정 패턴은 밀침으로 이동하지 않는다. |
| 체력·방어·회복 | 체력 기본 100 × 최대 2.00(랭크로 오른 최대 HP는 신규 시작 시 채움). 방어는 영구+봉인석+조건 합계 최대 12, 실제 피해 하한 1. 초당 재생 최대 1.0 HP, 즉시 회복은 전투 1초당 최대 2 HP, 항상 최대 HP 이내. 동시 즉시 회복은 한도만큼만 처리. 치명 피격에는 회복 이벤트가 없다. |
| 이동·XP·수집 | 이동 보너스 합산 +80%p 상한(요한의 팬티 +10%p/단계 포함). XP 일반 합산 +75%p 상한(두루마리 +8%p/단계 포함), 기존 Lv.20/40 +100%p는 상한 뒤 기존 `GrowthLedger` 방식으로 별도 적용. 획득 반경 0.70 × 최대 2.20. 골드 지급 정의는 그대로 사용한다. |

`sling` 진화 기본 5발 + 돌 보조 최대 2 + 추가 투석 1 = 8이다. 새 도전의 기본형 Lv.8은 4+2+1=7, 구매를 하지 않은 새 진화형은 보조 최대에서 7이다. 재개하는 종전 규칙은 `max(5,4+2)=6`과 저장된 연사 일정을 유지한다. 기본 5번 돌 등 순번 노드는 보조·특화로 추가한 슬롯과 별개다. 조건부 추가 돌은 원본 슬롯 외의 별도 예산을 쓴다.

### 이벤트 우선순위와 저장 단위

1. 60Hz 전투 시간만 누적한다. 고정 스텝에 맞지 않는 일정은 저장한 예정 시각 이상의 첫 틱에 실행한다. 반복 일정의 다음 예정 시각은 실제 처리 틱이 아니라 직전 예정 시각에 간격을 더해 구한다. 행의 대상별 타격은 해당 적의 다음 유효 틱에서 한 번 처리한 후 같은 틱의 공용 타격에서 제외한다. 조건 비교는 포함 경계(‘이하/이상’), 거리 조건은 적 중심과 공격 기준점의 거리를 쓴다. 전투 시작 시간, 피격·처치·획득 시각, 연속 이동, 표식은 아래 범위에서 다음 단계로 이어진다. 무피격 조건은 라운드 첫 프레임부터 세고, ‘같은 도전’ 항목만 직전 라운드 전투 누적 시각을 포함한다. 무이동은 이동 입력 0으로 판정한다.
2. 순서가 같은 사건은 무기 ID → 주기/개체 ID → 적 ID 순서로 처리한다. 먼저 무기의 기본 탐색·표적 규칙을 적용한다. 둘 이상의 선택 효과가 활성화되면 명시된 단일 보스 조건 → 명시된 정예 우선 → 명시된 군집 우선 → 무기의 기본 후보 비교 → 적 ID 순서다. 행에서 우선 대상을 따로 지정할 때만 보스·정예 우선이 활성화된다. 정예는 보스 본체 또는 해당 라운드의 유효 일반 웨이브 종 중 기본 최대 HP가 같은 웨이브 전체 종의 최솟값의 3배 이상인 적이다. 여기서 웨이브 전체란 해당 라운드의 모든 웨이브에 등장하는 종의 합집합이다. 보스가 소환한 적은 별도 역할이며 이 판정에서는 일반 적이다. 정예 판정은 전투 규칙의 파생값으로 계산해 라운드 카탈로그·지문은 그대로 둔다. HP는 판정 직전의 현재/최대 값으로 검사한다. 최근접은 제곱 거리, 군집은 후보 중심 반경 1.5 내 적 수(다른 값이 지정되면 해당 값)로 비교한다. 전방 기준은 기존 Facing이고 초기 실패 대체 방향은 +X다.
3. 주기와 명령 순번은 1부터 세고, `N번째` 또는 `N마다` 행은 N의 배수에서 발동한다. 누적 조건의 카운터는 무기·노드 단위이며 라운드 경계에서 초기화한다. 내부 대기 중에는 추가로 채우거나 예약하지 않는다. ‘다음’ 효과의 만료가 생략된 경우 같은 라운드의 다음 해당 사건까지 유지, 중첩은 1개이고 재발동 시 갱신한다. 효과가 활성일 때 동일 표식은 갱신하며 별도 행의 보너스는 상한 안에서 합산한다.
4. 형태와 공간/시간 보너스는 개체 생성 또는 음파 타격 스케줄이 확정될 때 기록한다. 표적·방향은 각 발사나 타격이 일어날 때 기본 추적 규칙으로 정하며 고정 좌표·조준 잠금·예고가 명시된 경우 예약 시 기록한다. 피해·치명·방어의 HP·거리·연속 적중 조건은 사건 직전에 평가하고, 타격이 확정된 뒤 처치·표식·카운터를 갱신한다. 여러 대상의 첫/마지막은 해당 행의 주기·개체에 속한 예정 원본 공격을 뜻한다. 지속 구역의 기본 틱은 0.5초(개체의 첫 유효 시점부터, 수명 종료점 미포함).
5. 원본은 무기 기본 주기·진화 기본 패턴의 주 공격이다. 진화 연쇄·잔류·파동과 노드가 만들어 낸 추가 타격, 반격은 보조로 태그한다. 보조 타격 피해는 상한을 적용한 해당 개체의 치명 전 원본 피해에 계수(생략 시 25%)를 한 번 곱하며 같은 원본의 복제로 취급한다. 보조 피해로 최종 처치해도 기존 골드·XP 정산은 그대로다. 보조 타격·반격은 조건부 킬·적중 카운터·치명·추가 생성의 입력에서 제외한다. 행이 직접 지목하는 자식 변형(페이지의 잉크·관통, 불씨의 첫 충돌 불자리 등)은 그 자식에 허용된 후속 단계·횟수를 생성 시 등록한다. 해당 자식이 유효한 첫 충돌·종료 조건을 충족할 때만 예약된 변형을 한 번 실행한다. 일반 발동 처리기로 되돌아가지 않으며 하나의 묶음에 최대 두 단계(부모의 보조 및 등록한 후속 1단계)만 허용한다. 배경 일반 적이 없는 경우 대체 표적이 명시된 행만 대체한다.
6. 확률은 전투 RNG의 무기·노드 전용 스트림을 쓴다. 종전 RNG를 소비하지 않는다. 수치 효과가 0이거나 대상이 없으면 굴리지 않는다. 한 생성형 노드의 최소 내부 대기는 무기당 1초, 행에 지정하면 그 값과 함께 적용한다. 주기 기반 노드는 별도 지정이 없어도 주기당 한 번이고 동일 노드의 보조 생성 그룹 대기 하한은 1초다. 넓이·속도·예산을 바꾸는 정적 행은 대기를 쓰지 않는다.
7. 출처별 타격 이력으로 중첩을 제한한다. 같은 종류의 한 무기 잔류장은 동일 적에게 같은 고정 틱에 하나만 적용(높은 피해, 동률은 낮은 ID 우선). 같은 공격의 여러 부채꼴은 별도 지시가 없으면 대상당 한 번이다. 기본 진화 연쇄는 최대 3회, 해당 노드 구매 시 4회, 기본 연쇄 내 대상 재방문 금지다. 같은 적의 같은 단계 위치 충돌은 한 번만 인정한다.
8. 전역 이동 투사체 최대 256(원본용 192칸을 예약하고 보조 투사체는 최대 64), 비투사체 지역 최대 48(원본 32칸 예약, 보조 최대 16), 추가 공격 그룹은 무기당 동시 4, 전체 동시 24다. 새 보조 후보가 한도를 넘으면 아직 스폰하지 않은 보조 후보부터 생략하고 기록한다. 원본이 전역 한도에 도달하면 신규 초과분만 생략하며 예약·피해·후속 RNG를 다시 만들지 않는다. 원본 생략 건수가 실기 검증에서 0이어야 출시할 수 있다. 적탄 제거는 전역 1초에 1개·무기별 2초에 1개 이하, 실제 제거 시 소비하며 보스 지대·돌진에는 적용하지 않는다.
9. 상태가 화면 전환에 의해 망실되지 않도록 활성 개체와 함께 스케줄·동작·치명 RNG·적중 이력·타이머를 저장한다. 라운드 간에는 랭크·장비·진화·도전 누적 전투 시간 및 그 범위가 명시된 무피격 이력만 이어지고, 나머지 발동 상태와 개체는 버린다. 일반 웨이브에서 보스 입장까지 같은 라운드 ID를 쓴다. 기준의 보스 입장 시점에 제거하는 개체는 새 규칙에서도 해당 경계에서 제거하고, 자연 종료 보조 공격은 발생시키지 않는다.
