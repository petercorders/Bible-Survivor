# 신규 전투 무기 7종

수치는 [합산과 발동](../skill-tree-mvp-design.md#합산과-발동) 전 기본값이다. 피해는 타격당, 주기는 개시→개시다. 수량과 무기 레벨은 항상 별도다. 소환·지역·발사체는 슬롯을 추가로 차지하지 않는다. 공격은 모두 자동이며 적이 없을 때 위치 지정 무기는 대기한 뒤 첫 유효 틱에 개시한다. 방향 무기는 무표적이면 Facing으로 나간다. 소환체는 플레이어를 따라간다. 주기 초기값은 무기 획득 또는 라운드 입장 시각이며 명시된 점화·예고 지연을 제외하면 즉시 시작한다.

## 해금과 진화 진입

캐릭터 시작 무기 선택은 기존 3종이다. 새 전투 규칙의 도전에서 Rnn 영구 해금이 커밋되면 이후 레벨업과 보스 보상의 기존 랜덤 획득 풀에 들어간다. 해금 전에는 영구 미리보기만 가능하다. Lv.1 획득은 동일 무기 슬롯이 비어 있을 때에만 가능하고 반복 선택은 Lv.8까지 한 단계씩 올린다. 성장 후보 최대 3개, 무기/보조 슬롯 각 6개, 레벨업 골드 25(후보가 0일 때), 기존 보상 골드 100(아이템·진화 후보가 3개 미만일 때 보상에 포함) 정책을 유지한다. 같은 해금이 이전 도전에서 확정됐으면 새 R01부터 후보에 포함한다.

후보 창은 장비가 이미 조건을 갖췄을 때의 가장 빠른 보스 보상이다. 자연 플레이에서 해당 창에 만렙이 되는지는 시드별 검증으로 확인한다. 보상 후보를 만들 때 Lv.8과 대응 보조 ≥1, 기본형 장착을 확인한다. 이미 진화했거나 해금 정산 자체가 아직 진행 중이면 해당 진화 후보가 없다. 대상 후보는 캡처한 인벤토리를 기준으로 계산하며, 보스 보상 선택 때도 그대로 검증한다. v2는 적격 진화를 무기 ID 서수 순으로 정렬하고 기존 보상 ID 해시(처음 4바이트의 little-endian uint) % 후보 수에서 원형으로 최대 3개 뽑은 뒤 남은 칸에 기존 아이템과 골드 대체를 적용한다. 같은 보상은 같은 후보·순서를 유지하며 다음 보스의 후보는 다시 계산한다. v1에서는 기존 3종의 ID와 순서·해시·보상 정책을 그대로 쓴다.

진화 선택을 커밋하면 동일 슬롯의 표시와 공격 프로필을 진화형으로 교체한다. 레벨 8과 보조를 보존하며 보조는 소비하지 않는다. 이때 해당 무기 업적을 같은 커밋에 기록한다. 구 형태에서 이미 예약한 타격·이벤트는 취소하고, 새 형태는 다음 유효 전투 틱에 첫 주기를 시작한다. 개체 제거는 자연 종료로 처리하지 않는다. 기본 수치 교체 뒤 레벨·영구·보조 효과를 한 번 합산한다. 진화 전용 노드는 구매 당시의 도전이 끝나고 다음 도전에서 실제로 진화했을 때 켜진다.

진화 번개 보조 연쇄·충격파, 사자 도약의 후속 타격·포효, 메아리, 수로·가시·불길에는 재귀 발동을 금지한다. ‘진화 전이 시’나 ‘진화 도약 처치 시’처럼 전용 행이 참조하는 후속 효과는 해당 **기본 진화 묶음의** 유효 마지막 결과를 참조하며, 그 전용 행이 생성한 추가 전이·도약에는 전달하지 않는다. 복합 갈래가 타격 각도를 동시에 바꾸면 명시적 진화 원형과 포위 원형 → 내려찍기/선회 등 형태 교체 → 반각 증가 순으로 처리한다. 이동과 겹치는 지대 충돌은 60Hz 틱 내 결정적 궤적을 공유한다.

## 표현과 확인

|---|---|

요청할 규격은 논리 ID, 원본/진화, 32×32 아이콘(중심 피벗), 전투 스프라이트 상태별 프레임·피벗, 틱에 대응하는 표시 모드, 적탄·위험 타일과의 구분이다. 월드 표현은 고정 틱 상태에서 위치·각도·도달을 읽고 색·음향 외에 윤곽을 제공한다. 실제 아트 제작·Unity 연결은 구현 승인 단계에서 진행한다.
