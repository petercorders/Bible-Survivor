# 신명기 R31–R36과 여호수아 R37–R40

이전 버전의 R30 요단 앞 완료 저장은 그대로 읽힌다. 완료 화면에서 신명기 시작을 명시적으로 선택하면 R31을 진행하고, R36 느보산을 끝낸 뒤 여호수아 시작을 선택하면 R37을 진행한다. 두 진입 모두 저장에 실패하거나 결과를 확인하지 못하면 완료 화면과 기존 저장을 유지하며 같은 operation으로 다시 시도한다. 진입 시 기존 도전 ID, 골드, 성장, 장비와 보상 기록을 승계한다. R40 아이 성을 끝내면 완료를 저장하며, 다음 체크포인트 번호 41에는 진입할 수 없다.

## 결정 기록 (초기 수치)

모두 개발 초기 수치이며 자연 플레이 밸런스로 확정한 값이 아니다. 2026-11-19 이슈 #1에서 R21–R30 방식을 따르는 추천안으로 정했다.

- 책 배분: 신명기 6라운드(보스 R33·R36), 여호수아는 R37–R40 설치(보스 R39, 설치 끝 R40은 일반 라운드). 책이 3의 배수이고 보스로 끝나는 기존 흐름과, 설치 끝을 일반 라운드로 둔 R20 선례를 따랐다.
- 라운드 수치: 민수기 공식을 전역 오프셋 `o = 라운드 − 22`로 연장했다. 경험치 7200+200o, 완료 골드 420+20o, 적 생성 1560+60o, 체력 440+20o / 295+14o / 1070+35o, 3라운드 단위로 빠른 적 비율을 교대한다. 접촉 피해는 책마다 1씩 올렸다.

## 저장과 기록

- 기존 R01–R30 지문과 과거 보상 필드를 그대로 유지한다. R30 빌드에서 뽑은 R01–R30 지문 30개를 고정 파일로 두고 새 빌드 값과 비교한다.
- R21 이후 보스 기록은 순서가 검증되는 목록에 이어 붙인다. R40 완료 시점의 목록은 R21·R24·R27·R30·R33·R36·R39 순서이며 앞선 네 기록은 이전 빌드 저장의 내용 그대로다.
- R41 이상 체크포인트, 아직 설치되지 않은 보스 라운드(R42 등)의 보스 기록, 라운드와 맞지 않는 새 보상 정책, 알 수 없는 미래 보상을 담은 저장은 "새 버전 필요"로 거절하며 원본과 백업을 바꾸지 않는다.
- 설치된 보스 라운드의 기록이 남거나 빠지거나 순서가 바뀐 저장은 미래 저장이 아니라 손상으로 판정하며, R30 빌드와 같이 백업 파일을 읽는다. 이 손상 복구 경로는 이번 단계에서 바꾸지 않았다.
- 일부 책만 설치된 구성(신명기 미설치·여호수아 미설치)은 그 책 시작을 제안하지 않고 새 도전만 제안하며, 다음 책으로 넘어간 저장은 "새 버전 필요"로 읽기를 거절한다.

## 검증 범위

- Core 시험 전체(R40 추가 4개 포함)가 통과했다. 이전 빌드에서 만든 R30 완료 저장으로 신명기 진입의 쓰기 실패·재시도·중복 커밋, 여호수아 진입, 보스 기록 순서, 미래 저장 보존을 확인했다.
- Core에서 R16–R40 연속 좌표 전투를 완료하고 R33·R36·R39의 실제 처치와 예고·투사체 시점 저장 재개를 확인했다(`--r40-series sling 7`). 고정 테스트 장비와 체력을 사용했으므로 일반 난이도 밸런스는 미검증이다.
- 격리 사본 변이 6개를 모두 검출했다. 보스 기록이 R30 뒤로 이어지지 않는 옛 구조, 신명기·여호수아 진입을 일반 다음 라운드로 건너뛰는 경로, 신명기 완료 전 여호수아 진입, 라운드와 맞지 않는 보상 정책 허용, 민수기 지문 계약 변경이다. 이 중 보스 기록 변이는 저장 수명 검증이, 신명기 완료 전 여호수아 진입 변이는 재개 시 체크포인트 대조가 먼저 거절해 검출됐다.
- Unity EditMode 전체 408개와 라운드 진행 PlayMode 14개가 통과했다.
- 격리한 macOS 앱에서 이전 빌드가 직접 만든 R30 완료 저장으로 시작했다. 저장 파일을 바꾸지 않고 읽은 뒤 신명기 시작(Enter)으로 R31에 들어갔고, R36 완료 화면에서 여호수아 시작(Enter)으로 R37에 들어가 R40을 완료했다. 두 진입 모두 도전 ID와 골드가 유지됐다. 전투는 자동 입력과 테스트용 장비·체력으로 진행했다. R33·R36·R39에서 세 방향 예고 상태와 실제 적 발사체를 확인했다. 낮은 효과 캡처에는 HUD 예고 문구가 보이지만 보스와 예고선은 화면 밖에 있다(R30과 같은 구도). R40 완료 시점에 보스 기록은 R21–R39 순서였고 앞선 네 기록은 시드 저장과 같았다. 새 프로세스에서 R40 완료를 복원했고 신명기·여호수아·R41 진입을 제안하지 않았으며, 완료 화면에서 Enter를 두 번 누르고 일시정지를 풀어도 저장 파일이 바뀌지 않았다.
- 자연 플레이의 난이도 밸런스, 모바일 기기와 성능은 미검증이다.
