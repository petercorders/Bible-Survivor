# R61~R100 자연 성장 측정

이슈 #9 · 준비1

## 결정

- 수치 방식: C0
- 주무기 우선으로 R100까지 생존했다. 최저 처치율은 R98의 34.29%로 하한 33.74%를 넘겼다. C1은 정의를 검사했고 연속 측정은 생략했다.
- 주무기 우선의 R100 생존과 일반 라운드별 처치율로 판정했다. 하한은 R31~R60 일반 라운드 20개의 처치율 산술평균의 절반이다.
- 고르게는 동일한 시작 무기와 시드에서의 비교 정책이다. 이 정책의 R39 사망을 판정에서 제외하는 결정을 이슈 #9 Q3에 남겼다.

## 재현

```sh
bash tools/dotnet.sh run -c Release --project tools/BibleSurvivor.Sim -- --natural-growth main-weapon sling 7 C0
bash tools/dotnet.sh run -c Release --project tools/BibleSurvivor.Sim -- --natural-growth balanced sling 7 C0
```

이 명령은 설치 끝이 R60인 준비1 커밋의 측정 조건을 재현한다. 이후 라운드가 설치된 버전에서는 이 커밋으로 돌아와 실행한다. C1을 실행할 때는 마지막 인수를 C1으로 바꾼다. 두 정책은 레벨업과 보스 보상이 제안한 선택지만 사용하고 공통 이동을 사용했다. 이동은 적의 가능한 접근 거리와 빠져나갈 경로의 여유를 비교한다. 보스 전리품의 진화 제안이 동률이면 제안 순서를 사용한다.
R01~R60은 설치된 정의로 실행하며 R61~R100은 Sim의 메모리에서만 생성한다. C0는 라운드에서 22를 뺀 오프셋을 매 라운드 적용한다. C1은 각 책 첫 라운드에 한해 직전 라운드의 오프셋을 쓴다. 오프셋과 별도로 책당 기존 적 접촉·이동 증가량을 연장했다.
임시 보스는 기존 사슬 패턴을 사용한다. R60부터 보스마다 체력 3,500, 보상 골드 60, 몸과 투사체 피해 1을 더했다. 두 소환 체력 비율은 5%p씩 번갈아 올리되, 각각 95%, 90%에서 제한했다.
