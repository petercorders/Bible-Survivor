# 책별 타이틀과 첫 출전

Claude Fable 5.2와 Claude Design에서 설계한 창세기의 새벽 숲과 출애굽기의 밤 사막을 시작·재도전 화면에 적용했다. 책 이름과 진행 표시는 실제 세션을 따른다. 세션이 없는 새 도전에서는 빈 진행 표시를 보여 준다. 필요한 선택 에셋이 빠진 경우 기존 무기 선택 화면을 사용한다.

새 라운드로 실제 진입할 때 첫 출전 안내를 짧게 표시한다. 저장을 불러오거나 일시정지를 해제할 때 반복하지 않는다. 안내는 입력을 기다리게 하지 않으며, 필수 공격 예고 아래에 그린다. 효과 낮음에서는 안내가 움직이지 않고 0.8초 뒤 사라진다.

PC 관련 사례 18개가 통과했다. 660px·1100px·1400px에서 표시를 확인했고, 실제 키보드로 무기를 선택한 뒤 Enter를 다시 눌러도 두 번째 도전이 생기지 않음을 검증했다. 기존 효과 낮음의 흰 필수 예고선은 안내 레이어 위에 유지됐다. 새 진행 표시의 단색은 교정했고 기존 표시 경로의 일부 어두운 배경색에는 원본과 차이가 남는다. OS 마우스 전달, 모바일, 성능, 장시간 자연 진행은 검증 범위 밖이다. 게임 화면은 로컬 검증에만 사용했다.
