# 보스 동작 조합

이슈 #11 · R61~R100 준비2

보스 정의에서 돌진, 슬램, 세 갈래 사슬, 체력 문턱 소환을 선택한다. 주기가 있는 동작을 조합하면 동일한 예고와 공격 시점을 공유한다. 돌진과 사슬을 함께 선택하면 사슬 중심은 예고 때 고정한 돌진 방향을 쓴다. 소환은 별도의 체력 문턱으로 처리한다.

기존에는 R03·R06이 슬램, R12가 돌진, R09와 R15~R60 보스가 세 갈래 사슬을 사용했다. 각 정의에 동일한 동작과 소환을 지정했다. 기존 보스의 지문 형식과 `ChariotCharge` 저장 필드를 유지했다. 새 동작 조합은 별도 도형이나 에셋 없이 기존 상태 필드를 함께 사용한다. 이번 단계에서는 조합을 사용하는 신규 보스를 설치하지 않았다.

## 검증

- Core 236개 통과. 기존 R01~R60 지문과 R60 완료 저장, 기존 돌진·사슬·슬램을 포함한다.
- 실험용 정의로 돌진·슬램·사슬·소환 동시 사용, 소환 단독, 돌진 단독을 확인했다. 전투 스냅샷을 복원해 같은 틱의 도형·공격 결과를 비교했다.
- 격리 사본에서 R12 전용 분기, 사슬의 배타적 처리, 조합 조준 검증 제거, 이전 JSON 로더의 버전 판정으로 각각 되돌려 회귀를 검출했다. 돌진 단독 및 돌진·사슬 조합의 R63 테스트 정의를 격리 사본에서만 등록해 예고와 돌진 중 실제 저장·로드 및 도형을 비교했다.
- 리뷰 반영 후 Unity EditMode 465개 통과. 그래픽 장치를 끈 첫 배치의 폰트 래스터 실패는 그래픽 장치를 사용한 재실행에서 재현되지 않았다. QA 앱과 PlayMode는 제외했다.

신규 보스 HUD는 정의에 선택한 동작을 함께 표시한다. R01~R60에는 기존 표시 문구를 사용한다.
