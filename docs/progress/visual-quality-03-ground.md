# 책별 전장

Claude Fable 5.2와 Claude Design으로 책별 전장을 설계하고, 독립 검수를 마친 픽셀 에셋을 Unity에 연결했다. 실제 출애굽기 라운드에서 모래, 석판 길, 돌무더기, 마른 덤불을 그린다. 창세기는 풀밭과 흙길을 사용한다. 출애굽기 가장자리 그늘은 배우·경험치·필수 경고보다 아래에 그리며 효과 낮음에서는 가장자리 그늘을 끈다.

관련 사례 5개와 선택 에셋 묶음 누락 시 복원 검사가 통과했다. PC 빌드의 660px·1100px 창에서 창세기와 출애굽기 전장을 확인했다. 실제 출애굽기 경고의 흰 중심선과 어두운 외곽선은 효과 낮음에서도 유지됐고 두 전장에 표시된 파란 보너스 경험치 보석과 그 윤곽을 수치로 확인했다. 보석 색과 판정은 기존 데이터를 사용한다. 군집 전투 중 체감 가독성, 모바일, 자연 진행, 성능은 이번 검증 범위 밖이다.

책 문장 에셋은 후속 타이틀 연결을 위해 등록했다. 시작 화면, 첫 출전 안내, 보스 연출은 별도 작업이다. 실제 게임 화면은 로컬 검증에만 사용했다.
