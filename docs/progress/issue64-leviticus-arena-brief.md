# 레위기 R16–R21 전장 아트 후보

현재 여섯 라운드는 검토된 Book03 모래·길과 레위기 냉색 계열 색조를 사용한다. 라운드 전용으로 승인된 배경 원본과 해당 소품의 실제 화면 증거는 여섯 라운드 모두 없다. 다음 배치의 이야기 배경은 [R16–R20 진행 기록](R20.md)과 [R21 진행 기록](R30.md)을 따른다.

| 라운드 | 장절 | 대표 소품 후보 | 승인 전용 원본 |
|---|---|---|---|
| R16 아론의 위임과 첫 직무 | 레 8:1–12 | 접은 에봇과 관유 단지. R15 성막 건물을 반복하지 않고 위임 준비의 천과 토기에 초점을 둔다. | 미확보 |
| R17 정결의 길 | 레 14:3–8 | 진영 바깥의 낮은 토기와 백향목·우슬초 묶음. 시전 효과나 인물 표식 없이 물과 도구만 그린다. | 미확보 |
| R18 속죄일 | 레 16:4–10, 29–34 | 접은 세마포와 제비 두 표식을 놓은 매트. 표식은 게임 각색으로, 본문이 제비의 모양을 특정하지 않는다. | 미확보 |
| R19 이웃 돌봄 | 레 19:9–10 | 수확한 밭과 가장자리에 남겨 둔 이삭. 수집물처럼 움직이거나 반짝이지 않는다. | 미확보 |
| R20 희년 | 레 25:8–13 | 낮은 돌 받침 위의 나팔과 쉬는 밭 가장자리. 나팔은 정지 소품이며, 별도 발광과 소리를 추가하지 않는다. | 미확보 |
| R21 서원의 끝 | 레 27:14–15 | 작은 집 문턱과 평가를 상징하는 토기 저울. 저울은 시각 각색이며 상점이나 보상을 열지 않는다. | 미확보 |

원본 인계 단위는 고정 ID별 투명 PNG와 팔레트 인덱스 원본, 사이드카 SHA-256이다. 출애굽기와 같은 정지 1프레임·32 PPU를 기준으로 삼고 원근·셀·피벗은 각 실루엣을 대조한 뒤 정한다. 소품은 바닥에 고정하며 중앙 교차점과 HUD를 피한다. 1920×1080·660×440에서 기본·낮은 효과의 필수 예고와 XP를 구별할 수 있어야 한다. 기존 승인 지형의 재사용은 [R10–R180 감사표](issue64-arena-coverage.md)에 계속 기록한다.
