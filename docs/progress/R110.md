# R101~R110 캠페인 진행

이슈 #25에서 R100 완료 저장을 이어 욥기와 시편을 설치했다. 본문 및 장면은 캠페인 아이디어 기록 3절의 R101~R110에 대응한다.

| R | 본문 | 장면 | 대표 적 또는 보스 |
|---|---|---|---|
| 101 | 욥기 4:12–21 | 엘리바스의 밤 환상 | 밤에 스쳐 간 영의 속삭임 |
| 102 | 욥기 18, 38–42 | 폭풍 속 응답과 회복 | 공포의 왕, 지대와 사슬 |
| 103 | 시편 1 | 시냇가의 나무와 두 길 | 바람에 나는 겨 |
| 104 | 시편 23 | 사망의 음침한 골짜기 | 골짜기의 그림자 |
| 105 | 시편 46 | 흔들리는 산과 성의 강 | 뛰노는 바닷물, 슬램과 지대 |
| 106 | 시편 64 | 숨어서 쏘는 독한 말 | 화살 같은 독한 말 |
| 107 | 시편 73 | 미끄러질 뻔한 걸음 | 형통의 신기루 |
| 108 | 시편 91 | 지존자의 은밀한 곳 | 밤의 공포, 소환과 조준 |
| 109 | 시편 124 | 끊어진 올무 | 사냥꾼의 올무 |
| 110 | 시편 137 | 바벨론 강가의 수금 | 노래를 청하는 조롱 |

욥기 R102 완료 뒤 저장된 성장과 장비로 시편을 명시적으로 시작한다. 설치 끝은 R110이고 저장에는 다음 번호 R111이 기록된다. R111 진입은 차단된다. 기존 이동 역할별 스프라이트와 보스 동작 표시를 재사용한다.

수치는 준비4 #23에서 확정한 C7의 R101~R110을 적용했다. 전체 웨이브의 구간·체력·접촉·속도·생성 시점·경험치·골드와 세 보스의 수치 및 동작 조합을 C7 실험 정의와 시험에서 대조한다. 준비4의 판정은 시뮬레이션 결과다.

`tests/BibleSurvivor.Core.Tests/Fixtures/r110-build-complete-save.json`과 `r110-build-round-fingerprints.txt`를 다음 단계에서 이어 쓴다. 재생 시험은 R100 저장에서 시작하고, R103 진입의 디스크 쓰기 실패와 같은 요청 재시도를 실행한다. 종료 시 보스 기록과 R110 저장의 직렬화 바이트를 확인한다. 이전 R100 저장과 R01~R100 지문 파일은 이 변경의 diff에 없다.
