# R10–R180 실제 전장 환경 감사

기준은 #61의 `126c8fc`와 이 작업의 Unity 런타임 경로다. 정상 전투는 `AdamGame → AdamArtWorld.Draw → DrawTerrain`을 사용한다. 지형층은 공용 타일·길·장식, 창세기 또는 출애굽기 고정 소품 순이며 배우·드롭·경고가 그 위에 그려진다. #60 공개 R10 마지막 컷의 `DrawBackdrop`도 같은 `DrawTerrain`을 호출한다. 컷과 전장은 화면 크기에 맞춰 별도로 투영한다.

**감사 결과** · 기준 171개 중 공용 지형 171, 전용 성경 전장 소품 0, 승인된 전용 배경 원본 0. #64에서는 R10–R15 6개에 소품을 연결했고 v25 후속에서 독립 검수한 PNG 7종을 적용했다. R16–R180 165개는 공용 지형을 사용한다. 이미 Unity 검증용 임포트를 통과한 Book03 모래·판석·길·자갈·관목·음영은 계속 사용한다. 적·보스·투사체·전투 보상과 권별 색 곱은 전용 배경 수에 포함하지 않는다.

## 공용 지형의 실제 선택

S는 Book03의 모래·판석·교차로·자갈·관목·움푹한 땅으로, 색 곱이 없는 출애굽기 공용 세트다. 다음 코드는 같은 세트에 아래 RGB 곱을 적용한다. Book03 모래 세트가 설치되지 않은 경로에서는 기존 에덴 지형으로 돌아간다. C는 나머지 후반 권이 함께 사용하는 한 가지 색 곱이다.

## 라운드별 기록

이전 Player 화면은 R10–R15의 각 Unity UI 리뷰에서 확인할 수 있다. [R10](../reviews/R10-unity-ui.md) · [R11](../reviews/R11-unity-ui.md) · [R12](../reviews/R12-unity-ui.md) · [R13](../reviews/R13-unity-ui.md) · [R14](../reviews/R14-unity-ui.md) · [R15](../reviews/R15-unity-ui.md). 해당 리뷰의 HUD·배우·경고 화면은 #64의 기술 장식을 넣기 전 빌드다. R16–R180에서는 이 감사에서 대조할 라운드 전용 소품이 없었다.

전용 소품 열의 앞은 기준 브랜치, 뒤는 이 작업의 결과다. ‘화면’은 이 변경의 전용 환경을 대상으로 한 실제 화면 증거다. 기존 전투·완주 증거는 별도의 실행 범위다. #63의 컷신 후보 R43, R55, R67, R94, R121, R151, R166, R172, R180은 통합 시 장소를 대조한다. 그 컷신은 전장 적용으로 집계하지 않는다.
