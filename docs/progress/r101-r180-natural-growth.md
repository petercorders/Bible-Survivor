# R101~R180 자연 성장 수치 측정

`--natural-growth`는 설치된 R01~R100을 재생하고, R101부터 실험용 웨이브와 보스 정의를 메모리에서 이어 간다. 설치 책이 시작되는 라운드에서는 실제 책 진입 경로를 쓴다. 실험용 정의는 욥기 끝부터 열두 예언서까지의 책 경계와 승인된 보스 동작 조합을 따른다.

판정 실행은 슬링과 시드 7, 주무기 우선 정책을 사용한다. 같은 시드의 고르게 정책은 비교 기록이다. 설치 구간의 성장 및 회피 정책은 준비1과 같고, 임시 보스의 파선과 피해 지대는 추가 회피 대상으로 사용한다.

| 방식 | 웨이브 오프셋 | 보스 HP 증가 |
|---|---|---|
| C0 | 라운드 번호 − 22 | R99부터 보스당 3,500 |
| C1 | C0에서 각 새 책 첫 라운드의 오프셋만 1 감소 | R99부터 보스당 3,500 |
| C3 | 78 + ⌊(라운드 번호 − 100) / 2⌋ | R99부터 보스당 1,750 |

설치된 R100을 지나 R180까지 생존하고, R101~R180 일반 웨이브의 처치율 최저가 33.74% 이상이며, R180 보스를 900초 이내에 처치하는 첫 후보를 고른다. 처음에는 C0, C1, C3 순으로 비교했고, 이후 이슈 #23에서 승인된 후보를 추가했다.

확정 C7 재현 명령

```sh
bash tools/dotnet.sh run -c Release --project tools/BibleSurvivor.Sim -- --natural-growth main-weapon sling 7 C7
```

다른 후보는 마지막 인자를 `C0`, `C1`, `C3`, `C4`, `C5` 또는 `C6`로 바꿔 실행한다. 주무기 우선이 설치 구간에서 사망하거나 계측 오류로 끝나면 공통 구간을 먼저 확인한다.

측정은 실제 생성 수, 처치 수, 웨이브 시간 종료, 받은 피해, 보스 처치 초, 종료 사유, 모의 경과 초를 기록한다. 전체 모의 시간은 R180까지 완료했을 때 측정된다. 실제 플레이에서는 난이도와 재미를 별도로 확인해야 한다.
