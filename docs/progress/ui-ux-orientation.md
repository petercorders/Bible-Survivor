# 가로·세로 화면과 책 완료 흐름

이슈 #42의 첫 연결 범위다. [UI/UX 점검표](../ideas/ui-ux-audit.md)의 시작과 책 전환을 우선 적용한다.

- 모바일에서는 물리 화면 전체에서 동일한 전투 투영을 렌더러와 파티클이 사용한다. UI 좌표는 안전 영역과 정수 UI 배율을 사용한다. 지형 반복 범위는 모바일 뷰포트에 맞춰 계산한다. 로딩이나 완료 등 전투 스냅샷이 없는 화면에는 책의 지형을 사용한다.
- 일시정지와 경험치·장 번호를 별도 행에 배치했다. 모바일 시작과 성장, 보스 후보는 공통 카드 배치를 사용하고 책 완료와 복구 동작은 자신의 패널 안에 놓는다.
- 첫 무기 설명은 주변 회전, 전방 범위, 가까운 적 자동 조준을 표시한다. 책 완료에서는 이어 가기가 첫 키보드 초점이다. 새 도전은 독립된 화면에서 무기를 확정해야 시작한다. 숫자키 1–3은 책 완료와 새 도전 확인에 영향을 주지 않는다.

## 검증 범위

- 가로·세로의 물리 화면, 안전 영역 좌표, 패널과 HUD 교차 여부는 Unity 배치 시험에 포함한다.
- R09 완료 상태의 숫자키, Escape 취소와 원본 저장 유지, 키보드로 명시 새 도전, 두 번 확정, 다음 책 Enter는 Unity 입력 시험에 포함한다.
- Android·iOS 실기기에서의 터치 크기, 회전 이후 입력 해제, 양 방향 실제 렌더 및 지속 성능은 플랫폼별 후속 확인 항목이다.
- R180 기준 리비전에서도 장식용 적 사망 효과와 입자 포화 재현 두 PlayMode 사례가 같은 단정에서 실패했다. 전체 PlayMode 결과에는 해당 실패를 포함해 기록한다.
