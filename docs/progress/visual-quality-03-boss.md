# 보스 등장·격파·승리 연출

Claude Fable 5.2와 Claude Design에서 설계한 보스 연출을 Unity에 적용했다. 기존 등장 시간 동안 체력 막대를 단계적으로 표시하고, 실제 격파와 선택형 보상 화면에 각각 효과음을 연결했다. 선택형 보상은 책 문장과 청동 선을 함께 표시한다. 보상은 열리는 즉시 선택할 수 있다.

검수된 원본 효과음 세 개를 사용한다. 골드만 자동 지급되는 경우에는 격파음만 재생한다. 저장을 불러오거나 실패한 저장을 재시도할 때 지나간 소리를 다시 재생하지 않는다. 격파음과 승리음이 겹칠 때에는 격파음을 우선한다. 효과 낮음에서는 가득 찬 막대와 정적인 장식을 표시하며 필수 공격 예고는 유지한다.

EditMode 22개, Unity IMGUI 포인터 검사 2개, 격리 macOS Player 기술 확인 68개가 통과했다. 독립 코드는 실제 6.2 Sol로 검토했다. 일반 플레이에서의 두 소리의 체감, 기기별 음향 믹스, 앱 밖에서 전달하는 네이티브 마우스, 모바일과 성능은 미측정이다. 실제 게임 자료는 로컬 검증에만 사용했다.
