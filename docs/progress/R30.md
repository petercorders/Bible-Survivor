# 레위기 마무리와 민수기 R21–R30

이전 버전의 R20 완료 저장은 R21로 이어진다. R21 서원의 끝을 완료한 뒤 민수기 시작을 명시적으로 선택하면 R22를 진행한다. 저장에 실패하거나 결과를 확인하지 못하면 기존 완료 화면을 유지하며 같은 operation으로 재시도할 수 있다. 진입 시 기존 도전 ID, 성장, 장비와 보상 기록을 승계한다. R30 요단 앞을 끝내면 완료를 저장한다.

보스와 적은 창작 생물이다. 보스 네 마리는 각각 33,200 / 35,500 / 38,000 / 41,000 HP를 가지며, 예고 뒤 고정 세 방향 파편을 사용한다. 개발 초기 수치다. 기존 검수 에셋을 사용하고, 민수기 지형에 따뜻한 색조를 적용했다. 낮은 효과 설정에서 보스 예고와 발사체를 유지한다. Fable은 사용하지 않았다.

기존 R01–R20 지문과 과거 보상 필드를 유지하며, R21·R24·R27 기록을 순서가 검증되는 저장 목록에 추가한다. R30 보상과 클리어 기록은 현재 보스 기록에 저장되고, 다음 체크포인트 번호 31에는 진입할 수 없다. 미지원 저장이나 보상 정책은 원본과 백업을 보존한다.

## 검증 범위

- Core에서 R01–R30 연속 좌표 전투를 완료하고 R21·R24·R27·R30의 실제 처치와 각 예고·투사체 저장 재개를 확인했다. 고정 테스트 장비와 체력을 사용했으므로 일반 난이도 밸런스는 미검증이다.
- 새 책 진입의 실패·재시도·중복 요청, 보스 기록 순서, 이전 스키마에 들어간 신규 보스나 정책의 원본 보존을 테스트했다. 기록 덮어쓰기와 구버전 보호 누락 변이 모두 격리 사본에서 검출했다.
- 독립 검토에서 이전 빌드와 R01–R20 지문이 20개 모두 일치했다. 이전 빌드에서 직접 생성한 R20 완료 저장을 파일 변경 없이 읽고 R21 진입을 확인했다.
- Unity EditMode 전체 382개와 라운드 진행 PlayMode 14개가 통과했다.
- 격리한 macOS 앱에서 이전 빌드의 R20 완료 저장으로 시작해 R30을 완료했다. 전투는 자동 입력과 테스트용 장비·체력으로 진행했다. 네 보스의 세 방향 공격 예고와 실제 발사체를 확인했다. 새 프로세스에서도 R30 완료와 보상 기록을 복원했으며, 완료 화면에서 Enter를 눌러도 저장 파일이 바뀌지 않았다.
- 자연 플레이의 난이도 밸런스, 모바일 기기와 성능은 미검증이다.
