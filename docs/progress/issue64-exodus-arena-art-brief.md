# 출애굽기 전장 소품 · Claude Design 제작 요청

요청 범위는 정상 전장 지면에 들어가는 정지 소품이다. R10은 [#60의 마지막 컷](https://github.com/petercorders/Bible-Survivor/pull/60)에서 정상 전장으로 이어지는 기준 샷이다. 공개 런타임의 서쪽 가마와 동쪽 벽돌 더미를 동일한 방향으로 유지한다. v23 비공개 전경의 건조대·더미는 형태와 재질 참고 자료이며, 전장 소품으로 사용하려면 별도 인계와 승인이 필요하다. 디더 전환이 제품에 들어오면 두 더미가 겹쳐 보이는 구간을 확인한다.

전부 **제작 요청, 최종 납품·승인 대기**. 32 PPU, 1프레임, 0 fps, 정지 상태 하나, 투명 배경, 좌하단 픽셀 경계 피벗. 아트보드 주소와 팔레트 인덱스 픽셀 원본, 점 필터 1×/3× 미리보기, PNG·사이드카 및 SHA-256을 소품마다 제공한다. 승인된 Book03 모래·길 위에서 왼쪽 위 광원, 조용한 중간 명도, 바닥에 닿는 그림자를 기준으로 맞춘다. 큰 외곽선, 포화 적색·금색 경고와 XP 색, 장애물처럼 보이는 높은 울타리, 전술 표시, 애니메이션은 사용하지 않는다.

수락 기준은 1920×1080과 660×440의 동일한 바닥·피벗, 기본·낮은 효과 모드의 동일 실루엣, 중앙 교차로와 자막 및 보스 경고의 판독, 가마·벽돌 더미의 컷 전후 일치다. 모래 위 독립 아트 QA와 실제 플레이 검수 이후 승인된 ID별 원본을 연결한다. 기술 장식은 해당 소품의 최종 승인 전까지 유지한다.

요청은 지정된 Design 담당자의 작업공간으로 전달됐다. 담당자는 #63 첫 제작 배치 다음으로 이 요청을 접수했으며, #64 전용 보드 또는 승인된 소품 원본은 아직 도착하지 않았다.
