# R16 레위기 첫 라운드 Core

레위기 8~9장의 아론 위임과 첫 직무를 배경으로 한 첫 일반 전투다. 적 세 종은 게임용 창작 군세다. 제사장·제물·거룩한 불은 적 또는 공격으로 사용하지 않는다. 규칙은 일반 전투 180초, 생성 마감 170초, 동시 적 상한 120, 총 1,260체, 원시 XP 예산 6,000, 완료 골드 300이다. 모두 초기 수치이며 자연 플레이 난이도 실측은 없다. 누적 3라운드 보스 주기는 유지한다.

`LeviticusContent.Round()`와 `MonsterSpeeds`가 R16의 Core 콘텐츠 정의다. 기존 창세기·출애굽기 지문은 유지했다. 새 일반 적은 추적과 접촉만 사용한다. R16 전투·성장 정산·완료 후 between17 저장을 지원한다.

완료한 R15는 기존 출애굽기 완료 상태를 유지한다. `CanEnterLeviticus`와 `PrepareLeviticus`는 명시 전환에 사용할 복사 후보를 제공한다. 호출자는 기존 revision/operation ID 저장과 재읽기가 성공한 뒤 후보를 게시해야 한다. 취소는 후보 폐기다. 다섯 번째 완료 보스 기록은 R15에서 복사한다. 앞선 네 보스 기록, RunId, 장비, 진화, 성장, 영구 성장 스냅샷 및 프로필을 이어간다. R15 완료 보상 재지급은 없다. 새 전투는 World3이며 적탄·돌진·피격 시계를 넘기지 않는다. 기존 schema3에 선택 필드 한 개를 추가하고 R16 저장에만 허용한다.

## 검증 범위

- 관련 Core 3개다. 완료 R15 원본과 실패 직전 디스크 바이트 보존, 동일 연산 재시도, 다섯 보스 기록, R16 위치/전투 재생과 성장 정산 디스크 재개, 완료 보상 한 번, 미래 저장 원문 보존을 확인했다.
- 격리 변이는 R15 보스 기록을 기존 네 번째 칸에 기록하도록 바꿨다. 기준 0, 변이 1, 원복 0이며 R12 완료 기록 검증 실패로 잡았다.
- 독립 코드 리뷰에서 미설치 R16 체크포인트를 일반 저장 오류로 분류하던 문제를 확인했다. Core 전환이나 저장을 변경하지 않고 Unity 카탈로그에서 기존 버전 안내 경로로 분류하도록 교정했고, 독립 재검토와 격리 Unity EditMode 35개를 통과했다.
- Unity용 Core DLL과 빌드 입력 문서는 동기화했다. 설치된 플레이 콘텐츠는 여전히 R15까지다. 게임에 R16 체크포인트가 주어지면 원문을 보존하고 기존 버전 안내를 사용한다. 레위기 진입 컨트롤, 전용 적 아트, PC Player 실행, 모바일 및 자연 밸런스는 NOT_RUN이다. 실계정 저장에는 접근하지 않았다.
