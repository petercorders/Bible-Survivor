# 두 번째 비주얼 개선

Claude Fable 5.2와 Claude Design으로 시작·재도전 화면, 전투 HUD, 세 무기의 동작과 명중 반응을 설계했다. 독립 검수를 통과한 픽셀 에셋 9종을 Unity에 적용했다. 에셋 묶음이 빠진 설치는 기존 화면과 입력 경로로 돌아간다.

- 시작·재도전 화면에서 세 무기를 각각의 문장과 공격 형태로 구분한다. 방향키나 A/D로 카드를 고르고 Enter로 확정할 수 있다. 숫자 키와 클릭도 지원한다.
- 체력 값은 막대 안에 넣고, 경험치·타이머·보스 상태를 다시 배치했다. 세부 조작은 일시정지 메뉴로 옮겼다. 효과 낮음 설정에서는 장식용 전환 애니메이션을 생략한다.
- 턱뼈의 초승달형 충격파, 물맷돌의 균열, 성경의 페이지 효과는 실제 명중에만 나타난다. 발사와 공전 잔상은 실제 투사체와 책 위치에 연결한다. 효과 낮음에서도 필수 보스 예고와 명중 신호를 유지한다.

PC 관련 EditMode 31개와 실제 IMGUI PlayMode 3개가 통과했다. 실제 앱에서 방향키와 Enter로 물맷돌을 고르고 F6–F9, 일시정지 및 재개를 확인했다. 660px와 1100px의 높은 체력 수치가 타이머에 닿지 않는 것을 로컬 픽셀 검사로 확인했다. 데스크톱 마우스 이벤트의 OS 전달은 확인하지 못했다. 자연 진행·모바일·성능은 이번 PC 검증 범위 밖이다.

빌드와 검증 근거는 로컬 `evidence/visual-quality-02-20261118/handoff.md`에 있다. 실제 게임 이미지와 영상은 로컬 검증에만 사용했다.
