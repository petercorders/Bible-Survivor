# 레위기 R16~R20

출애굽기 완료 화면에서 레위기를 명시적으로 시작한다. 같은 저장을 재시도할 수 있고, 완료 저장이나 전환 후보가 자동으로 새 도전을 시작하지 않는다. 문서 수준의 기존 창세기·출애굽기 진행 규칙과 콘텐츠 지문을 보존했다. 영구 프로필, 도전 ID, 장비, 진화, 보조, 성장, 다섯 개 과거 보스 기록을 이어간다. R18에서 추가된 보스 완료 기록은 R19 진입부터 여섯 번째 과거 기록이 된다. R20 완료는 현재 설치 범위의 마지막 체크포인트다.

| 라운드 | 이야기 배경 | 적 생성 예산 | 원시 XP | 완료 골드 |
| --- | --- | ---: | ---: | ---: |
| 16 | 아론의 위임과 첫 직무 | 1260 | 6000 | 300 |
| 17 | 정결의 길 | 1320 | 6200 | 320 |
| 18 | 속죄일 | 1380 | 6400 | 340 |
| 19 | 이웃 돌봄 | 1440 | 6600 | 360 |
| 20 | 희년 | 1500 | 6800 | 380 |

제사장·제물·성물·의례는 이야기 배경이며 적은 창작 생물이다. 보스 잿빛 망령은 HP 31,000, 접촉 24, 5초마다 1초 예고 뒤 고정 방향 재 파편 3발, 파편 피해 20, 60/30% 체력에서 지원 적 각 6체, 처치 골드 560이다. 보스 선택 보상과 라운드 완료 보상은 기존 일회성 처리 경로를 사용한다. 수치는 개발 초기값이다.

레위기의 세 적과 보스는 검토된 R15 스프라이트의 이동·피격·예고·공격·사망 표현을 역할에 맞게 재사용한다. 지형은 기존 사막 타일을 차가운 색으로 처리한다. 낮은 효과 설정에서도 보스의 필수 세 방향 예고선과 실제 투사체가 표시된다. Fable을 사용하지 않았다.

## 검증

- Core 216개와 이전 버전 바이너리 호환 검사를 통과했다. 여섯 번째 보스 기록을 다섯 번째 칸에 쓰는 격리 변이는 기준/변이/원복 0/1/0에서 검출됐다.
- 고정 기술 성장·체력 설정으로 실제 좌표 전투를 R01부터 R20까지 실행했다. R16~R20 중간 저장과 R18 예고·적탄 저장의 동일 재생, 실제 R18 처치, R20 완료 저장을 확인했다. 일반 난이도의 자연 플레이 밸런스, 모바일과 성능을 뜻하지 않는다.
- 실제 Unity EditMode 356개가 모두 통과했다. PlayMode는 40개 중 38개와 R20까지의 키보드 진행 시험이 통과했다. 사망 효과·파티클 풀 시험 2개는 기존 커밋 `b843e25`에서도 같은 실패를 재현했다. 시행 전 코드와 로컬 XML을 함께 보존했다.
- 격리 macOS Player 한 빌드에서 R15 완료 저장 불러오기, Enter로 R16 진입, R18 실제 예고·적탄·격파, R20 완료를 확인했다. 새 프로세스에서 R20 완료를 재개하고 Enter가 저장을 변경하거나 새 도전을 시작하지 않는지 확인했다. 660×440에서 출애굽기 완료·레위기 진입, R18 저효과 경고, R20 완료 문구를 로컬에서 확인했다. 실제 사용자 저장에는 접근하지 않았다.
