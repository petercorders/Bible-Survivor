# 두 번째 비주얼 개선 회고

- 660px 시안에서 긴 체력 값이 타이머와 겹쳤다. 체력 값을 막대 안에 제한하고 실제 앱에서 긴 숫자와 타이머의 위치를 대조했다. 앞으로 좁은 화면 설계부터 긴 실제 값을 사례로 사용한다.
- Unity가 33자리 스크립트 GUID 세 개를 무시했다. 32자리로 고친 뒤 관련 검사를 통과했다. 신규 메타데이터를 검토할 때 중복뿐 아니라 형식도 확인한다.
- 실제 앱에서 정지한 마우스의 위치가 방향키 포커스를 덮어썼다. 호버를 실제 포인터 이벤트로 제한하고 Enter와 클릭 경로를 분리했다. 격리 사본에 이전 경로를 되살렸을 때 회귀 검사가 실패했고 수정본은 통과했다.
- 데스크톱 마우스 이벤트 전달은 확인하지 못했다. 기존 권한으로 실제 IMGUI 클릭 동작을 검사했고, 데스크톱 입력 전달 결과와 구분해 기록했다.
