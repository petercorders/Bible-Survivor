# #63 컷신 작업 회고

- 같은 연결편의 R09·R10 두 재생 구간을 공통 표로 표현하니 11편과 12개 저장 경계를 함께 검증할 수 있었다.
- 리뷰에서 입력 해제 프레임과 IMGUI 이벤트 소비 순서 문제를 발견했다. 한 번 놓고 다시 누르는 이동과 실제 MouseDown/MouseUp을 회귀 테스트에 남겼다.
- 로컬 디스플레이의 창 모드 최대 높이가 1018px였다. 화면 캡처 스크립트는 전체 화면과 창 모드 모두에서 이미지 실제 크기를 검증한다.
- 승인된 기술 시제품을 먼저 검증해 Draft에 올렸고, Design 원본은 제작 담당 일정과 별도로 검수했다. v24 파생본의 공개 범위를 담당자에게 확인해 원본과 참조판을 비공개 인계에 유지했다.
- 작은 창에서 컷신 좌표로 전장 좌표를 두 번 옮기는 문제가 보였다. 실제 게임의 전장 좌표와 컷신의 클립 영역을 별도로 적용해 보정했다.
- 후속 제작 때는 첫 비공개 인계 직후 작은 창에서 자막, 실제 전장과 만나는 마지막 프레임, 효과 저감 정지본을 먼저 확인한다.
- A·B묶음은 캡션을 먼저 원본 컷 순서에 맞췄다. 실제 네 창 크기에서 푸른 성문·야간 성벽·요나의 폭풍과 저감 정지를 확인했고, 실제 전장 RGB를 모델 팔레트와 대조했다.
- 후속 아트 검증은 미디어와 자막에 필요한 범위로 좁혔다. 공개 파생본 범위를 납품마다 기록하고 Core 장시간 시험과 기존 변이를 재사용했다.
