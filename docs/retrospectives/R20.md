# R20 회고

전환 지원 범위를 지문·상태·호스트 카탈로그에서 각각 확인했다. 초기 R20 통합 시험은 R17 저장 허용 목록이 아직 적용되지 않아 실패했고, 명시된 상태 목록을 반영해 수정했다. 독립 리뷰에서 레위기 적의 스프라이트 별칭을 분기 선택에만 적용하고 클립 조회에 적용하지 않은 문제를 찾아 한 번 변환한 ID를 양쪽에서 사용하도록 교정했다. 원본 실패 기록과 저장 기록 덮어쓰기 변이 로그는 로컬 QA 근거에 보존했다.

Core, Unity 호스트, 월드 파일을 분리해 일부 작업을 병렬 처리했다. 독립 리뷰에 Sol 6.2를 사용했고 사용자가 보류한 Fable은 사용하지 않았다. 공급자 사용량은 실제 세션 구간만 기록했으며 비용과 절감률을 추정하지 않았다.

아트·폰트 원본 상대경로를 요구하는 Editor 시험은 격리본에 원본을 복사해 재실행했다. 오래된 성경 아트 시험은 이후 승인된 시각 효과와 턱뼈 아이콘의 우선순위를 반영하도록 시험만 수정했다. 폰트 래스터와 PlayMode는 그래픽 장치가 있는 모드에서 다시 실행했다. PlayMode의 나머지 2건은 선행 커밋에서도 같은 실패를 재현해 R20 변경과 구분했다.
