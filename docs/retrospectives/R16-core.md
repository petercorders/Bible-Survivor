# R16 Core 회고

처음 정산 시험은 실제 이동 구간에서 얻은 드롭 XP가 성장 선택을 여는 점을 반영하지 않았다. 그 다음 시험은 마지막 성장 선택이 완료까지 자동 적용하는 기존 동작을 중복 호출했다. 초기 로그를 보존하고 실제 선택 전 정산 대기, 선택을 끝낼 때의 자동 완료, 직후 차단과 완료 저장 재개까지 시험하도록 교정했다. Core의 성장 동작은 바꾸지 않았다.

저장 전환 대상에는 기존 네 번째 기록이 남아 있어야 한다. 이에 맞춰 격리 사본에서 다섯 번째 대입을 네 번째 대입으로 바꾼 변이로 기록 덮어쓰기 회귀를 재현했다.

기존 Unity R15 테스트는 cloud를 항상 보유한다고 가정했다. 넓힌 회귀 묶음에서 이전 보상이 보조 6칸을 cloud 없이 채운 표본이 실패했다. 원본 XML을 보존하고, 완료 보상의 요구 레벨을 해치지 않는 장착 중 보조의 레벨을 한 단계만 내리도록 시험 준비를 교정했다. 제품의 장비 규칙은 그대로다.

사용량은 현재 Codex 세션 구간만 기록했다. Fable은 사용하지 않았고 비용은 미계산이다. 하네스 학습 규칙은 수정하지 않았다.
