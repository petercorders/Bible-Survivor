# R01 추가 GC — Unity 독립 좌표 전투

상태: 좌표 전투 구현과 68개 전체 검사·독립 코드 리뷰 완료. GC 후 커밋·원격 업로드·CI 확인 단계로 진행한다. Unity/기기 검증은 NOT_RUN이다.

## 사용자 교정과 범위

사용자 교정: "코드 유니티 필요없는거 진행해달라니까?" 및 "그래픽도 계속 개발도 계속이야". 앞선 개발에서는 Unity 실행 게이트를 기다리며 독립적으로 가능한 코어의 이동·자동공격·명중·타깃·거리 회수 작업을 멈췄다. 이는 사용자의 병행 진행 의도와 달랐다.

처리: 같은 R01 범위에서 `docs/harness/r01-offline-battle-plan.md`에 구체 구현을 기록하고 전투 담당과 통합 담당이 병렬로 코드/CLI/저장/시험을 구현한다. 그래픽 담당은 기존 별도 루프를 계속한다. 프로젝트 지도는 기술적인 실제 선행 조건을 구분하도록 갱신했다. 전역 학습 entries/overview는 변경하지 않는다.

## 검증·리뷰 기록

- 기존 45개 규칙 시험과 처치 주입 시뮬레이션은 회귀 기준으로 유지한다.
- 추가 코드는 실제 좌표 이동·공격·명중을 통해 처치를 생성하며 직접 Kill 호출로 시뮬레이션을 대체하지 않는다.
- 저장 왕복은 진행 중 좌표·공격/투사체·드롭·난수·고정 step 상태까지 다룬다.
- 새 좌표 전투를 포함한 전체 68개 시험이 실제 .NET SDK에서 PASS다. 기존 모드와 새 좌표 전투 모드를 각각 세 무기로 실행했고 진행 중 JSON 저장/복원도 확인했다.
- 독립 리뷰 MEDIUM: 중첩 hit 목록의 null 원소가 NRE를 일으켜 백업 복구를 우회했다. 실제 원문 JSON `OrbitHits:[null]`로 실패를 재현하고 모든 DTO의 null 원소를 검증에서 거절하도록 수정했다. 뒤이어 `Wave.Active:[null]`의 같은 경로도 현재/World 없는 이전 저장 각각으로 재현·수정했다.
- 독립 리뷰 MEDIUM: 과거 World.Time과 현재 Run.Wave.Elapsed를 함께 저장할 수 있었다. 시험이 정상 저장 덮어쓰기를 관찰한 뒤, 시간/적/드롭/lifecycle 교차 정합 검사로 저장 전에 거절하도록 수정했다. 두 지적과 동일 null 계열을 독립 검토자가 수정 원문·회귀 시험에서 해결 확인했다.
- 구현 단계에서 반격으로 죽은 적을 접촉 순회가 다시 참조하는 문제와 테스트가 원본/복원 세션의 mutable RunState를 공유하는 문제를 실제 실패로 확인했다. ID 재조회와 실제 JSON 복사로 각각 수정했다.
- 투사체의 동일 대상 중복 명중 방지 삭제와 중첩 null 검증 삭제는 격리 사본에서 실제 시험 실패를 확인했다. 이 두 회귀·stale World·Wave null 회귀를 기존 7개와 함께 재사용 변이 검사에 연결했다. 로컬 실행 원문은 gitignored evidence 폴더에 보존한다.
- 최종 재사용 변이 검사 11건 모두 컴파일 오류가 아닌 실제 시험 실패로 검출했다. 각 실행은 고유 evidence 경로에 보존하며 작업 트리 원본은 바꾸지 않았다.

코어 검증 결과의 PASS는 좌표 규칙과 저장/복원 범위다. CLI 자동 봇의 근접 무기 낮은 처치 수를 맞추려고 원본 피해·주기·예산을 변경하지 않았다. 실제 밸런스 조정은 사용자 입력/플레이 검증에 따른 별도 작업이다. Unity 설치 실패는 확인된 디스크 공간 부족이며 이 독립 코드 작업을 중단시키지 않았다.

## 실행 선택 회고

전투 코어·행동 시험을 한 구현 담당에, CLI·직렬화·검증 연결을 통합 담당에 배정했다. 작업 파일을 나눠 그래픽 루프와도 충돌하지 않는다. 독립 리뷰는 구현 완료 후 별도 세션에서 수행한다. 실제 모델/추론·입출력/cache/reasoning 사용량은 제공되지 않은 범위에서 미측정이며, 위임의 토큰 절감 효과를 추정하지 않는다.

추가 개선 후보는 **실제 의존성이 있는 게이트만 차단하고, 승인된 독립 과업은 계속 진행**하는 것이다. 이번 작업 분리와 프로젝트 지도 갱신을 근거로 남기고, 전역 학습 규칙 승격은 구체 선택 없이 수행하지 않는다. 라운드 사이클 종료 후 검증·리뷰·이 회고를 포함해 커밋·push 및 원격 CI 확인까지 진행한다.
