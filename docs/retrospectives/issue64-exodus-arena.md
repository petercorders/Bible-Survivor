# #64 출애굽기 전장 1차 회고

- 171개 라운드의 실제 지형 호출과 권 경계를 먼저 대조해 공용 지형 위의 색상 변화와 승인된 전용 소품을 혼동하지 않았다. 첫 비교에서 Book03에 포함된 전투용 왕관 UI는 배경 집계에서 제외했다.
- #60 최종 컷과 정상 전장이 이미 공유하는 지형 함수에 연결했다. 컷신 담당 소스와 전투 규칙을 유지하면서 동일한 R10 모티프가 양쪽에 들어간다.
- 첫 Roslyn 컴파일에서 구조체 생성자 확정 할당 오류가 나왔다. 가시 여부를 생성자 바깥에서 평가하도록 수정했다. 독립 리뷰가 지적한 과거 화면 증거와 R14 아론 본문을 보완했다.
- R13 표시 분기를 제거한 별도 사본에서 관리 코드 스모크가 실패했다. 원본은 6개 모티프의 투영·기록 검사를 통과했다.
- 다음 배치에서는 먼저 공용 렌더 경로와 이미 승인된 소품의 등록 단위를 고정하고 같은 방식으로 라운드별 감사와 기술 배치를 추가한다. [적용 및 검증 범위](../progress/issue64-exodus-arena.md)
- 첫 보스 시험은 화면 밖 보스를 사용해 문구만 관측됐다. 보스를 화면 안에 둔 기술 저장을 별도로 만들고 같은 무음 빌드에서 두 해상도의 방향선을 확인했다. 이후 증거용 보스는 시작 전에 카메라 안 배치를 검증한다.
