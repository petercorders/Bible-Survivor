# 출애굽기 기획 GC

2026-11-17. 창세기와 같은 제작 과정은 재사용하되 책마다9라운드를 강제하지 않는다. 훌/여호수아의 같은 아말렉 전투를 나누어 분량을 늘리는9안보다 초점인물6명의6라운드 초안을 채택했다. 모세의 모든 사건을 그 라운드에 독점시키면 홍해 뒤 공동체/시내산 순서가 되감기므로 이후 사건에서 조연 등장을 허용한다.

독립 Sol 기획검토는 읽기 전용 한 담당만 사용했다. 구현자/Editor/아트 제작자를 아직 가동했다고 보고하지 않는다. 기존9상한·genesis고정·완료receipt를 직접 좁게 확인하고 전역 그래프 생성/전체시험/새 빌드를 추가하지 않았다. 최초 탐색은 존재하지 않는 Session.cs를 포함해 exit2였고 실제 AdamSession.cs를 찾아 수정했다. 새 소스/저장 변경은 없다.

최종 두 문서의 독립 기획검토 PASS:6라운드/누적R12·R15 보스·기적과 창작 구분·조연 행위 보존에 막는 모순 없음. 아론 구간 압축과 성막 창작전투 한계는 계속 명시한다. `git diff --check` exit0. 커밋 훅이 기존 창세기 Core171/171·CLI/portable·아트/폰트/R02 계약을 자동 재검사해 전부 exit0였다. 출애굽기는 아직 콘텐츠가 없으므로 출애굽기 .NET/Unity/앱 시험은 NOT_RUN이며 이 기존 회귀 결과를 새 챕터 검증으로 전용하지 않는다. 이 실행기록 문구만 보정하는 amend에는 완료한 훅을 재실행하지 않는다.

다음 구현의 핵심은 새 몬스터 수가 아니라 기존 창세기 완료 저장에서의 연속 진입·상한과식별자·중복보상 방지다. R10 전환과 한 라운드의 관련검사부터 진행하고 R11~15를 일괄 복사하지 않는다. 전투 숫자는 미결 초안이며 본문 사건과 창작 적/보스를 구분한다. 문서 변경 검증만으로 Unity/자연난이도를 PASS로 세지 않는다. 모델 청구/절감률은 미측정, 전역 GC 규칙 승격 없음.
