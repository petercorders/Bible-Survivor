# R30 회고

보스 순서와 보상 기록을 별도의 목록으로 추가해 이전 여섯 개의 저장 필드와 지문을 보존했다. 독립 리뷰에서 구형 스키마의 보스 오배치가 원본을 보호하는 오류 분류에 먼저 도달하도록 수정했다. 복구가 가능한 손상과 버전이 앞서는 원본을 구분하는 테스트를 스키마 1·2에 추가했다.

Core, Unity 호스트, 월드 구현의 파일 소유자를 분리했다. Unity Editor와 macOS 테스트 앱은 통합 담당만 실행했다. 기존 승인 에셋을 활용했고 Fable을 호출하지 않았다. 공급자 사용량은 각 세션이 기록했으며 비용·절감률은 추정하지 않았다.

전체 EditMode 첫 실행에서 이전 설치 끝인 R21의 제목을 계속 거절하던 UI 테스트 7개를 찾았다. 기존 출애굽기 제목 확인을 유지하면서 거절 대상으로 새 설치 경계 R31을 사용했고, 전체 382개를 다시 통과했다.
