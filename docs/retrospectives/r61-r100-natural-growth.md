# R61~R100 자연 성장 측정 회고

- R02·R19 피해 직전 위치를 기록해 회피 정책을 보완했다. 직전 입력은 적에게서 벗어나는 경우가 많았고, 피격 시 이미 적이 밀집해 있었다.
- 보스 보상 선택을 재현하려면 전투 시드와 함께 메모리의 run ID도 고정해야 했다.
- 임시 R61에서 설치 카탈로그 조회가 실패했다. R60부터 R63까지의 짧은 경계 검사를 추가로 실행한 뒤 연속 측정을 재시도했다.
- R93가 기존 러너의 틱 제한에 걸렸다. 이후 별도의 Sim 실행 한도를 사용했다.
- 다음 실험에서는 연속 측정 전에 미래 첫 웨이브와 첫 보스 진입을 짧게 확인한다.
- Orca 재시작으로 연속 실행이 끊겨 R01부터 다시 측정했다. 앞선 실행과 R92까지 각 행이 일치했다.
