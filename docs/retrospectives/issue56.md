# #56 회고

- 결정. Design 제품 연결이 인증 화면에서 막혀, 기존 게임 에셋으로 기술 검증을 진행했다. Design 화면과 승인된 원본이 있어야 픽셀 화풍 검수 및 변환을 시작할 수 있다.
- 처음 EditMode 실행에서는 Metal 없이 폰트 래스터를 검사했고 격리 사본에 R60 경고 테스트가 사용하는 Core 픽스처가 없었다. Metal과 픽스처를 함께 사용한 496건 실행은 통과했다. 기존 캡처와 프로젝트를 보존했다.
- 독립 리뷰가 시작 키와 같은 프레임에 전투 시간이 누적되는 경로와 다시 보기 버튼의 겹침을 확인했다. 입력 분기 후 시네마틱을 다시 검사하고, 전투 시뮬레이션의 잔여 시간도 0인지 검사했다. 다시 보기 버튼을 시작 머릿장의 오른쪽과 책 완료 패널의 독립 행에 배치했다.
- 다음 검증에서 바꿔 볼 것. 격리 사본 옆에 필요한 읽기 전용 Core 픽스처와 그래픽 게이트를 준비한 후 한 번만 전체 EditMode를 실행한다.
- 첫 1080p Player에서 자연 종료 직후 새 이동 키가 무시되는 경로를 재현했다. 종료 프레임에 입력이 비어 있었는지 확인하도록 수정하고 1080p와 660×440을 다시 통과했다. 누락 빌드의 기존 진입 경로도 검증했다.
- 타이머·저장 결함을 격리 사본에 각각 되돌리면 전투 누적 시간과 정산 실패 시 재생 차단 검사가 실패했다. 복원 후 두 검사가 다시 통과했다.
- 사용자 수정으로 육지 동물까지 여섯 컷으로 줄이고 시작 봉인과 엔딩 두루마리를 가장자리에 배치했다. 사용 중인 Mac에서 E2E·GUI·오디오를 중지했고, 최신 장면은 명령행 컴파일과 정적 검토까지만 진행했다. 원본 캡처는 수정 전 근거로 보존했다.
- R09 엔딩과 R10 오프닝은 같은 회랑 구도를 그리며 공통 모티프 ID를 기록한다. 입력 전환은 계속하기의 기존 저장 작업을 따라가게 했다. 원본 저장이 사라지고 유효한 백업만 남은 경우를 독립 리뷰에서 확인해 테스트에 추가했다. 최신 Player 검증은 Mac 사용 제한으로 보류했다.
