# 성경 책·후광 가독성 개선

2026-11-15 사용자 플레이 피드백: 이펙트가 생겼지만 성경 디테일이 부족하고 히트박스처럼 테두리가 보인다. 담당자의 읽기 진단에서 디버그 판정선이 아니라 매 프레임 책 뒤에 표시되는 `fx_bible-glow_static_20`의 얇은 금색 둥근 사각 원본임을 확인했다. lowFX는 optional 후광만 끄고 core 책을 유지한다.

기존 Art03·manifest/79PNG는 유지하고 별도 `art-bible-readability-01/` 시각 sidecar 후보를 준비한다. 대상 stable ID는 `fx_bible-glow_static_20`과 `wpn_bible-book_spin_16`이다. 기존 셀 크기/발이 아닌 중심 pivot/PPU/정렬/flip·기본 책 모양은 현재 계약을 읽어 인계하고, 전투 수치·회전 반경/속도·판정/장비·성장/저장에는 영향이 없어야 한다.

- 후광: 사각/둥근 사각의 닫힌 테두리와 네 모서리를 제거한다. 책에 밀착한 작고 비정형/부드러운 픽셀 빛으로 제한하고, 여러 책이 겹쳐도 큰 박스·장판으로 보이지 않게 한다. 화면 전체 점멸 금지, lowFX에서는 계속 꺼진다.
- 책: 표지·책등·종이 단면이16px에서도 구분되게 명암/실루엣을 보강한다. 글자를 억지로 넣지 않는다.2프레임 유지안을 우선하며 명료화에 꼭 필요할 때만 적은 추가 프레임을 제안한다. 외형 때문에 판정이나 표시 크기를 바꾸지 않는다.
- 제안 검토: 현재/후보 각1안의 실제 배율·밝고 어두운 바닥·여러 책 혼합/lowFX 대표 보드와 작은 동작 미리보기만 준비한다. 전체 픽셀/회전/해상도 행렬이나 새 검증 프레임워크를 만들지 않는다.
- 작업 소유: 지정 Claude 디자인 담당의 외부 새 폴더만. 제품/Unity/기존 원본/사용자 플레이 앱·저장/기기/QA 문서는 변경하지 않는다. 제품 연결/호스팅과 스크립트 픽셀 출력을 구분하고 독립 아트 검토 뒤 Unity 작성자에게 연결한다.
