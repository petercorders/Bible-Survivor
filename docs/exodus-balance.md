# 챕터 2 출애굽기 — 기획 초안 1

2026-11-17. 사용자 요청: 창세기를 진행한 방식으로 출애굽기를 진행한다. 기존 지속 승인으로 기획·관련 구현·독립 리뷰·프로젝트 GC·커밋·업로드를 이어가되, 이 문서는 **제작 전 기획 초안**이다. 아래 적·보스는 성경 본문의 실제 생물이 아니라 압제·불신·우상화를 형상화한 사탄 군세의 창작 디자인이다. 원전의 인물이나 민족 자체를 악마로 설정하지 않는다. 수치·자연 난이도·구현·플레이 검증은 아직 NOT_RUN이다.

## 구성과 원칙

- 66권은 챕터이며 모든 책을 9라운드로 고정하지 않는다. 출애굽기는 주요 사건을 중복하지 않는 **6라운드 권고안**이다. 추가 라운드를 만들려고 모세를 여러 명목으로 나누지 않는다.
- 인물당 초점 라운드는 한 번이다. 이후 다른 인물의 사건에서 조연으로 등장하는 것은 허용한다. 부아·여호수아·훌·이드로·오홀리압의 고유 역할은 소개문에서 보존한다.
- 출애굽기 C02-R01~R06 = 누적 R10~R15. 보스는 누적 3라운드마다이므로 R12·R15. 화면에는 챕터·내부 라운드를 표시하고 저장에는 안정적인 chapter/round 식별을 사용한다.
- 일반 전투 180초, 0~60/60~120/120~170초 유한 생성, 170~180초 정리. 기존 적을 웨이브 전환 시 삭제하지 않는다. 혼합 생성·동시 상한·완료 조건은 창세기와 같다.
- 플레이어는 계속 사용자 자신이다. 인물을 조작하거나 인물/민간인의 호위 HP를 새로 관리하지 않는다. 버프·디버프를 이야기마다 의무적으로 붙이지 않는다.
- 재앙·홍해·만나·시내산의 임재는 적의 능력이 아니다. 재앙을 플레이어가 쓰러뜨려야 하는 적으로 만들거나 성막·언약궤를 악마 보스로 만들지 않는다.

요게벳 라운드의 아기·바구니는 배경 이야기이며 피격·실패 대상이 아니다. 모세 라운드는 소명에서 홍해까지 압축하고 시내산을 미리 끝내지 않는다. 보스는 마지막 추격을 형상화한 별도 전투이며, 처치 후 홍해 건넘을 짧은 배경 전환으로 제시한다. 플레이어의 보스 처치가 기적의 원인이라는 설명은 하지 않는다.

미리암은 홍해 노래의 인물이다. 마라·만나는 동행 공동체의 이후 사건으로 포함하며 미리암이 물을 고치거나 만나를 내렸다고 서술하지 않는다. 패주의 잔영은 실제로 살아남은 이집트 병사라는 설정이 아니다.

아론 라운드는 압축 폭이 크므로 도입 문구로 순서를 잇는다: 여호수아가 전선에서 싸움 → 아론과 훌이 모세의 손을 받침 → 이드로의 분담 조언 → 시내산 언약과 제사장 부르심 → 금송아지의 실패. 해당 행위를 모두 아론에게 귀속하지 않는다. 율법·제사장 직분 자체를 적이나 저주로 표현하지 않는다.

성막 제작 중 이 군세와 실제 싸웠다는 본문은 없다. 마지막 라운드는 제작·협력을 방해하는 창작 전투라는 점을 소개문에 명시하며, 출40장의 성막 완성과 임재를 안전한 완료 연출로 남긴다. 금송아지 사건을 마지막에 다시 재현하지 않는다.

## 챕터 사이의 성장과 저장

1. 창세기 완료 저장을 읽고 출애굽기 진입을 명시적으로 제공한다. 업데이트 후 Load만으로 전투를 시작하거나 기존 도전을 새 도전으로 바꾸지 않는다.
2. `between10`의 완료된 창세기 저장은 R10 진입 대기로 해석할 수 있어야 한다. 기존 R03/R06/R09의 보스 receipt와 후보·보상 상태를 보존하며 재지급하지 않는다.
3. 무기/보조·레벨·XP·진화·골드·구매 스냅샷을 이어간다. 완료 회복 후 새 적/타이머/드롭만 초기화한다. 사망하면 여전히 창세기 R01부터, 영구 구매/해금/잔액은 유지한다.
4. 슬롯6+6·기존 무기 강화 상한·진화 규칙은 유지한다. 고갈 일반 성장25gold/보스 보상 fallback100gold를 재사용하며 장기 무한 강화를 임의 도입하지 않는다. 새 무기/420노드 구현은 이번 기본 범위에 포함하지 않는다.
5. 창세기 말기의 이미 완성된 빌드를 기준으로 적 수치 초기값을 산정한다. R10을 R01의 약한 적으로 재시작하거나 매 라운드 체력/생성량을 기계적으로 폭증시키지 않는다. 회복 구간과 압박 구간을 교차하고 cap은 PC 측정 없이120 초과로 올리지 않는다.
6. 초기 구현은 R10 하나의 전환·저장·전투를 끝낸 뒤 R11~R15로 넓힌다. R15 완료는 다음 책 대기로 저장하고 레위기를 자동 제작하지 않는다.
