# R02 enemy sidecar — approved offline snapshot

This public subset contains the three original game sheets, editable palette/grid source, deterministic generators/converter/manifest, contract/checker, and producer regression tests. It excludes private Design canvas/URLs, review archives/boards, caches and raw QA evidence. Offline independent review R02-01 through R02-04 is CLOSED; engine integration is a separate gate.

The PNG pixels were generated by Claude-authored procedural scripts, not exported from Claude Design. The producer reports a Design-type review canvas; remote canvas rendering is not verified by this integration and no private canvas is distributed here. Rights/provenance are preserved verbatim in `export/manifest_r02.json`: original project-specific art, no third-party image references/traces, existing Art03 master palette plus the R02 extension. Review-only Galmuri fonts are not included in sprites and remain in their separately licensed font package.

Three128×32 sheets, four32×32 frames each, PPU32, bottom-left pixel-edge pivot(16,1), Point/no mip/no compression. B1/B2/B3 run8/8/6fps loop. Right-facing originals receive one renderer/parent flipX. B1 floats with the existing small Art03 shadow; B2/B3 are grounded with the existing wide shadow. No collision or combat rule changes.

Unity importer/build/runtime validation is separate. Original full generation verification needs numpy/Pillow; run on a disposable package copy with sibling Art03/font packages because producer selftest resolves those sibling references and verify writes its own result log.
