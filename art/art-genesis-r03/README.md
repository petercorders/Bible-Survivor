# R03 actor sidecar

Subset of the independently reviewed production draft. Public inputs preserve the original manifest/contract/palette/source and generator rights/provenance. Game PNGs are script output, not exports from the Design presentation canvas. Private canvas/RESULT/session data/review boards are omitted.

Eight runtime sheets: C1/C2/C3, boss move/windup/impact/death and boss shadow. The ten-entry source manifest is preserved verbatim as the reviewed reference; the warning-reference PNG and optional impact decal are deliberately not copied or imported. Runtime warning geometry is generated from the actual Core locked target/radius through WorldProjection, above actors/effects and below HUD, always in lowFX. It never takes radius from a PNG or boss cell.

Resources/ArtR03/index.json is the pinned eight-entry import contract derived from that manifest. PPU32, FullRect, Point/Clamp, no mip/compression, unchanged alpha, registered foot pivots and single UV flip. Intro holds move0. Windup0/1/2 follows the Core1.2s clock, impact2@10 and death4@6 play once.

Nephilim tyrant is a game adaptation, not a claim that Noah/family/God/flood are enemies. Original Art03/R02/font/Bible sidecar inputs remain unchanged. Actual Unity/PC scope and limits are recorded in docs/progress/R03-unity.md.
