# R08 actor sidecar

외부 `bible-survivors-docs/art-genesis-r08`의 독립 아트QA PASS인 H1~3 move3PNG/12frames와 manifest/pixel-source/계약/재생성 스크립트만 보존한 whitelist다. 기존 원본·폰트·GUID/이전 sidecar는 교체하지 않고 private Design/blob/리뷰 보드·새 패키지는 제외한다.

`ArtR08/index.json`은 정확3클립/manifest/PNG 해시를 pin한다.32px/PPU32/pivot16,1/Point/FullRect/right-parentflip와 binary alpha 규칙, fps9/5/7, H1 small·H2/H3 wide 기존 그림자를 사용한다. 세 종은 추적/접촉이며 사슬·곡식은 actor 내부 표현이다. 속박/섭취성장/새위험선·탄막·피해지형은 추가하지 않는다. 고갈 재화 카드는 Core 후보 정책이며 아트·전투 수치를 바꾸지 않는다. 실제 Unity 근거와 기술 준비/한계는 `docs/progress/R08-unity.md`에서 구분한다.
