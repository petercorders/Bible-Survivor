# 영구 스킬 상점과 신규 무기 아트

Claude Design 보드 9개에 직접 작성한 픽셀 프레임에서 63개 가로 띠를 내보냈다. 출처는 #47의 승인된 디자인 작업과 보드 게시 v30 `1795414526-1ede`다. 이 게임을 위해 제작한 원본이며 제3자 스프라이트를 사용하지 않았다. 캔버스 게시 접근은 담당 작업공간에서 관리한다. [사용자 승인](https://github.com/petercorders/Bible-Survivor/issues/47#issuecomment-7092122492)

`source/issue47-production_v1.json`은 게시 프레임을 펼친 픽셀 행이다. 이 파일의 `production-draft` 문구는 제작 당시 상태라 출처 해시와 함께 보존한다. `python3 -I art/art-issue47/verify.py`로 소스 픽셀, 계약, 두 팔레트, Unity 등록과 63개 PNG를 대조한다. Unity 리소스에는 32 PPU와 이진 알파를 사용한다.

독립 화면 QA는 63개 원본과 두 종류 6슬롯 구성에서 7무기의 기본·진화, 일반·저효과 화면을 확인했다. 1280×720에서 상점 포커스 다섯 상태와 사자 두 종의 짧은 겹침을 다시 확인했다. 겹친 작은 사자의 스프라이트 위치는 읽기 쉽게 잠시 이동하고, 발 위치와 공격 경계는 실제 월드 위치를 표시한다. 잔류선 대비를 낮췄고 저효과에서는 장식 두 개를 줄였다. 소스와 달라진 표준 등록은 16px 노드 아트와 바닥에 맞춘 번개 피벗이다.

개별 추가 기술의 모든 프레임, 정확한 1920×1080 창, 660×440의 포커스 다섯 상태, 하드웨어 입력, 모바일과 성능은 후속 검증 대상이다.
