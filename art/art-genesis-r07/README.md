# R07 actor sidecar

외부 `bible-survivors-docs/art-genesis-r07`의 독립 아트 QA PASS인 G1~3 move3PNG·12프레임과 manifest/pixel-source/계약/재생성 스크립트만 복사했다. private Design/blob·리뷰 보드·새 패키지는 제외했다. 기존 원본/폰트/GUID와 이전 sidecar를 교체하지 않는다.

`ArtR07/index.json`은 정확3클립과 manifest/PNG 해시를 pin한다.32px/PPU32/pivot16,1/Point/FullRect/right-parentflip 규칙, G1/G3 9fps·G2 7fps, G1/G2 wide·G3 small 기존 그림자를 사용한다. 표정/모피는 장식이며 무적위장·새 공격·디버프가 없다. G3는 한 sprite당 한 actor이고 실제 Core 좌우 생성 좌표를 그대로 그린다. Unity 재배치/공유HP/연결선은 없다. 실제 초기 좌우 화면·기술 준비·한계는 `docs/progress/R07-unity.md`에 구분한다.
